# Install OpenJDK 17 in Debian 13 Trixie

## 1. OpenJDK 17 설치 시도

```Bash
sudo apt install openjdk-17-jdk
# Error: Unable to locate package openjdk-17-jdk
```

## 2. 설치가 불가능한 이유

* [24.04.3 LTS](/01_Environment_Setup/[2026.01.02]_Ubuntu_VM.md#02-aarch64-ubuntu-이미지-다운로드)에서는 다양한 JDK 버전을 공식 저장소에서 제공하고 있습니다.

* 데비안은 각 메이저 릴리스마다 하나의 Java LTS 버전을 기본으로 채택하는 경향이 있습니다.

    * Debian 12 (Bookworm): OpenJDK 17이 기본이었습니다.

    * Debian 13 (Trixie): OpenJDK 21이 기본 LTS 버전으로 채택되었습니다.

* Debian 13(Trixie) 저장소에서는 `openjdk-17` 패키지가 제외되고 `openjdk-21`로 대체되었습니다.

## 3. 해결 방법

* Adoptium (Temurin) 외부 저장소 사용

    ```Bash
    # 1. 키링 폴더 생성 및 GPG 키 다운로드
    sudo mkdir -p /etc/apt/keyrings
    wget -O - https://packages.adoptium.net/artifactory/api/gpg/key/public | sudo gpg --dearmor -o /etc/apt/keyrings/adoptium.gpg

    # 2. Adoptium 저장소 추가
    echo "deb [signed-by=/etc/apt/keyrings/adoptium.gpg] https://packages.adoptium.net/artifactory/deb trixie main" | sudo tee /etc/apt/sources.list.d/adoptium.list

    # 3. 설치
    sudo apt update
    sudo apt install temurin-17-jdk
    ```

## 4. 확인

```Bash
java --version
```

* 출력 확인

    ```Plain text
    openjdk 17.0.18 2026-01-20
    OpenJDK Runtime Environment Temurin-17.0.18+8 (build 17.0.18+8)
    OpenJDK 64-Bit Server VM Temurin-17.0.18+8 (build 17.0.18+8, mixed mode, sharing)
    ```

* 여러 Java 버전 관리하기

    * 만약 시스템에 OpenJDK 21과 Temurin 17이 동시에 설치된 경우, 아래 명령어를 통해 기본값 (Default)을 언제든지 바꿀 수 있습니다.

        ```Bash
        sudo update-alternatives --config java
        ```

# Oracle Database 23ai (23c) 신규 문법

## 1. `SELECT` 절 `FROM dual` 생략

기존에는 계산식이나 함수만 호출할 때도 반드시 `FROM dual`을 붙여야 했으나, 이제는 생략이 가능

* 기존 방식 (Prior to 23c)

    ```SQL
    SELECT 3.5, -3.5, +3.5,
    ABS(3.5), ABS(-3.5), ABS(+3.5) FROM dual;
    ```

* **신규 방식 (Oracle 23c+ & MySQL 동일)**

    ```SQL
    SELECT 3.5, -3.5, +3.5,
    ABS(3.5), ABS(-3.5), ABS(+3.5);
    ```

## 2. 조건부 DDL 지원 (`IF EXISTS` / `IF NOT EXISTS`)

객체가 존재하지 않거나 이미 존재할 때 발생하는 에러를 방지하기 위해 별도의 PL/SQL 예외 처리를 해야 했던 번거로움이 사라졌습니다.

* 기존 방식 (Prior to 23c)

    ```SQL
    -- 테이블이 없으면 ORA-00942 에러 발생
    DROP TABLE emp;
    ```

* **신규 방식 (Oracle 23c+ & MySQL 동일)**

    ```SQL
    DROP TABLE IF EXISTS emp;
    CREATE TABLE IF NOT EXISTS dept (deptno NUMBER(4), dname VARCHAR2(20));
    ```

## 3. 다중 레코드 `INSERT`

`INSERT ALL`이라는 복잡한 문법 대신, 표준 SQL 방식인 `VALUES` 절 뒤의 쉼표 구분을 통해 여러 행을 한 번에 삽입할 수 있습니다.

* 기존 방식 (Prior to 23c)

    ```SQL
    INSERT ALL
        INTO emp01 (ename, empno) VALUES ('재석', 1)
        INTO emp01 (ename, empno) VALUES ('연아', 2)
    SELECT * FROM dual;
    ```

* **신규 방식 (Oracle 23c+ & MySQL 동일)**

    ```SQL
    INSERT INTO emp01 (ename, empno) VALUES ('재석', 1), ('연아', 2);
    ```

## 4. `HAVING` 절 내 별칭 (`AS`) 인식 및 사용 차이

* 기존 방식 (Prior to 23c)

   ```SQL
    -- inline view
    SELECT * FROM (
                    SELECT deptno, ROUND(AVG(sal)) AS 평균급여
                    FROM emp GROUP BY deptno)
    WHERE "평균급여" >= 2000;
    ```

* **신규 방식 (Oracle 23c+ & MySQL 동일)**

    ```SQL
    SELECT deptno, ROUND(AVG(sal)) AS "평균급여"
    FROM emp GROUP BY deptno
    HAVING "평균급여" >= 2000;
    ```

## 5. `GROUP BY` 절 내 별칭 (`AS`) 인식 및 사용 차이

* 기존 방식 (Prior to 23c)

    ```SQL
    SELECT TO_CHAR(hiredate, 'YYYY') AS 입사년도, COUNT(*)
    FROM emp GROUP BY TO_CHAR(hiredate, 'YYYY');
    ```

* **신규 방식 (Oracle 23c+ & MySQL 동일)**

    ```SQL
    SELECT TO_CHAR(hiredate, 'YYYY') AS "입사년도", COUNT(*)
    FROM emp GROUP BY "입사년도";
    ```

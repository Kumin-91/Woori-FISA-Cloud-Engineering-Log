### 1.3 RDBMS 연결 확인 (JNDI & Connection Pool)

* 서버 내부에 별칭으로 등록된 리소스를 검색 및 반환

* `java:/comp/env` (JNDI 네이밍 컨텍스트)

    * Component: 애플리케이션을 구성하는 재사용 가능한 객체

    * Environment: 컴포넌트가 실행될 때 참조하는 환경 설정 정보가 저장된 경로

* `DataSource`: 미리 생성된 데이터베이스 연결 객체들을 효율적으로 관리하는 Connection Pool 매니저

```Java
// 1. 서버 설정 (context.xml 등)에 등록된 전체 자원 검색을 위한 초기화
// WAS의 네이밍 서비스에 접근하기 위한 진입점 객체를 생성
Context initContext = new InitialContext();
			
// 2. 자바 컴포넌트의 환경 리소스가 정의된 표준 경로 탐색
// "java:/comp/env"는 웹 애플리케이션의 리소스가 배포되는 기본 위치
Context envContext  = (Context) initContext.lookup("java:/comp/env");

// 3. 설정 파일에 매핑된 이름으로 DataSource 객체 획득
// DataSource는 설정된 최대 개수만큼 Connection을 미리 생성하여 관리
DataSource ds = (DataSource) envContext.lookup("jdbc/myoracle");
			
// 4. 관리 중인 Connection Pool로부터 이미 생성된 Connection 객체 대여
// 매번 새로운 물리적 연결을 생성하지 않고, 준비된 객체를 재사용하여 성능을 최적화
Connection conn = ds.getConnection();
```

## 2. HTML & Servlet 작성

### 2.1 HTML

* Query String 활용: URL 뒤에 `?command=값` 형태로 명령어를 추가하여 전송

* 이동 방식: 버튼 클릭 시 `location.href`를 이용해 지정된 서블릿 경로로 이동하며 데이터를 전달

```Html
<button onclick="location.href='fisa/dept?command=all'">부서 정보들 요청</button>
```

### 2.1 Servlet 로직

    1. 요청 구분: command 파라미터를 통해 사용자의 의도 파악

    2. 비즈니스 로직 실행: DAO를 통해 DB 데이터 확보 (Model 영역)

    3. View 출력 위임: 결과 데이터를 request에 담아 JSP로 Forward (View 영역)

### 2.2 요청 분기 및 View 위임
   
```Java
protected void service(HttpServletRequest request, HttpServletResponse response)throws ServletException, IOException {
    // 1. 요청 명령어 (command) 추출
    String command = request.getParameter("command");

    // 2. 명령어에 따른 로직 분기 (Command 패턴)
    // 문자열 비교 시 NullPointerException 방지
    if ("all".equals(command)) {
        try {
            // [Model] DB에서 부서 전체 정보 조회
            ArrayList<DeptDTO> depts = DeptDAO.deptAll();

            if (depts != null && !depts.isEmpty()) {
                // [Success] 데이터가 존재할 경우
                // 1. 이동할 JSP 페이지에서 사용할 수 있도록 request 객체에 데이터 바인딩
                // 2. 데이터 유지 및 서버 내부 이동을 위해 Forward 방식 사용
                request.setAttribute("depts", depts);
                request.getRequestDispatcher("../deptallviewfinal.jsp").forward(request, response);
            } 
            else {
                // [Empty] 조회된 데이터가 없는 경우
                // 유연한 처리를 위해 별도의 안내 페이지나 에러 메시지 처리 로직 호출
                // response.sendRedirect("../emptyData.jsp");
            }
        } catch (SQLException e) {
            e.printStackTrace();
            // [Error] DB 연동 중 예외 발생
            // 사용자에게 친숙한 에러 페이지로 이동하거나 로그 기록  
            // response.sendRedirect("../error.jsp");
        }
    } 
    else if ("insert".equals(command)) {
        // [Model] 데이터 삽입 로직 처리 예정
    } 
    else {
        // [Invalid] 정의되지 않은 잘못된 요청 처리
    }
}
```

## 4. JSP Tag 종류 정리

### 4.1 JSP 목적

* Client에게 Java Data를 출력하기 위한 스펙

### 4.2 JSP 특징

* Web Container가 자동으로 Servlet으로 변환 후 컴파일

* JSP 내부에는 자동으로 생성되는 객체 존재: 변수명 선언 없이 호출

    1. `out`

        * `PrintWriter`의 자식 출력 API

        * Client 브라우저로 전달

    2. `request`

        * `HttpServletRequest` 객체의 참조 변수

    3. `response`

        * `HttpServletResponse` 객체의 참조 변수

    4. `session`

        * `HttpSession` 객체 참조

        * Servlet의 경우, 사용을 위해서 `getSession` 메소드로 생성 필수

        * JSP의 경우, `getSession` 호출 없이 생성 혹은 이미 생성된 `HttpSession` 객체 제공

        * JSP의 경우, `HttpSession` 사용하지 않을 경우, page 지시자 사용 (`<%@ page session="false" %>`)

### 4.3 JSP Tag 종류

1번, 2번은 정통 Tag, 현 시점에서는 가급적 사용 지양 (일반 Java 코드와 혼용해서 개발하는 Tag)

#### 1. JSP Scripting tag

* 기본 형식: `<% %>`

    a. **지시자: `<%@ ... %>` (중요)**

    * page 지시자: `import`, `contentType`

    * taglib 지시자: 외부 지원 tag 사용을 위해 필요

    b. **주석: `<%-- ... --%>` (중요)**

    * client에게 전송되지 않는 주석 (보안을 고려한 주석)

    c. 자바 코드 구현 Tag

    * `doGet` or `doPost` or `service` 구현부 적용 Tag
	
    *  사용 지양

	* `<% 순수자바코드 %>`

	* `<%= 브라우저에 출력 %>`

    d. 선언자 `<%! ... %>`

    * 멤버변수와 메소드 구현

#### 2. JSP Action Tag

* `<jsp:tag명>`

* 주요 Tag
	
    * Forward Tag: `<jsp:forward page="이동페이지" />`

#### 3. **EL (Expression Language) (중요)**

* 브라우저에 데이터 출력 Tag: `${ ... } `

* 추가 library 필요로 하지 않음

#### 4. **JSTL (Jsp Standard Tag Library) (중요)**

* EL 문법 필수로 사용하며, Java 코드를 최소화 할 수 있음

* JSP에서 권장되는 Tag

* 별도의 library 필요 (필요시 Apache 사이트에서 직접 다운로드 가능)

    * taglibs-standard-impl-1.2.5-migrated-0.0.1.jar

    * taglibs-standard-spec-1.2.5-migrated-0.0.1.jar

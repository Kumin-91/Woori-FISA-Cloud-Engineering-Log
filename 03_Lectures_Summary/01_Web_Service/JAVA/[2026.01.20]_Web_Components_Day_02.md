# Web Components Day 02

## 1. 페이지 이동 방식

### 1.1 Forward

* 서버 내부 이동: 서버 내부에서 리소스만 변경되는 것이므로 브라우저는 이동 사실을 알지 못하며, 따라서 주소창이 변경되지 않습니다.

* 객체 유지: 기존의 `HttpServletRequest`와 `HttpServletResponse` 객체가 그대로 전달되므로, `setAttribute()` 등으로 저장한 데이터를 다음 페이지에서 활용할 수 있습니다.

* 주요 사용: 주로 검색 결과 출력이나 데이터 처리 후 특정 JSP 페이지로 화면을 전환할 때 사용합니다.

```Java
// 서버 내부에서 "two"라는 매핑 경로로 요청을 전달
request.getRequestDispatcher("two").forward(request, response);
```

### 1.2 Redirect

* 클라이언트 재요청: 서버가 브라우저에게 새로운 주소로 다시 접속하라고 응답 (302)을 보냅니다.

* 객체 초기화: 브라우저가 완전히 새로운 URL로 다시 요청을 보내기 때문에 기존의 `Request` 객체는 소멸하고 새로운 `Request` 객체가 생성됩니다.

* 주요 사용: 로그인 성공 후 메인 페이지 이동이나, 글쓰기 완료 후 목록 페이지로 이동할 때 (새로고침에 의한 중복 등록 방지) 사용합니다.

```Java
// 브라우저에게 새로운 주소로 이동할 것을 지시
response.sendRedirect("two");

// HTML 응답을 통한 수동 리다이렉트 예시
response.setContentType("text/html;charset=UTF-8");
PrintWriter out = response.getWriter();
out.println("<a href='two'>two로 이동</a>");
out.close();
```

## 2. Session

* 서버 측 저장소: 접속한 클라이언트의 상태 정보를 브라우저가 아닌 서버 메모리에 저장하여 관리합니다.

* 데이터 영속성: 브라우저를 종료하거나 세션 만료 전까지 데이터가 유지되므로, Redirect 방식으로 페이지를 이동해도 데이터가 손실되지 않고 공유됩니다.

```Java
// 1. 세션 객체 생성 또는 참조
// 기존 세션이 있으면 반환하고, 없으면 새로 생성함
HttpSession session = request.getSession(); 
System.out.println("생성된 고유 ID: " + session.getId());

// 2. 데이터 저장 (Key-Value 쌍)
// 서버 메모리에 객체 타입 (Object)으로 저장됨
session.setAttribute("id", id);
session.setAttribute("name", "미우");

// 3. 데이터 추출 (다른 Servlet이나 JSP에서 활용)
// 반환 타입이 Object이므로 적절한 형변환 (Casting)이 필요함
String savedId = (String)session.getAttribute("id");

// 4. 세션 무효화 (로그아웃 등)
// 서버 메모리에서 해당 세션 정보를 즉시 삭제함
session.invalidate();
```

## 3. Cookie

* 주의점: 쿠키는 서버가 클라이언트에게 보내는 응답 (Response) 헤더에 실려 전송됩니다. 따라서 현재 실행 중인 서블릿 로직에서 추가한 쿠키는 다음 요청 (Request)부터 유효합니다.

    * Forward 불가: 서버 내부 이동인 Forward는 동일한 요청 사이클 내에 있으므로, 방금 추가한 쿠키를 `request.getCookies()`로 바로 확인할 수 없습니다.

    * Redirect 필수: 클라이언트가 응답을 받고 새로운 요청을 보내야만 헤더에 쿠키가 포함되어 들어오기 때문에, 쿠키를 즉시 활용하려면 Redirect 방식을 사용해야 합니다.

### 3.1 쿠키 데이터 저장

```Java
// 1. 새로운 쿠키 생성 (Key-Value 쌍)
// 실습 시 한글 데이터는 인코딩 처리가 필요할 수 있습니다.
Cookie cId = new Cookie("id", request.getParameter("id"));
Cookie cName = new Cookie("name", "미우");

// 2. 유효 기간 설정 (초 단위)
cId.setMaxAge(60 * 60 * 24); // 24시간 유지
cName.setMaxAge(60 * 60 * 24 * 365); // 1년 유지

// 3. 클라이언트에 응답 헤더로 전송
response.addCookie(cId);
response.addCookie(cName);
```

### 3.2 쿠키 데이터 사용 및 무효화

```Java
// 모든 쿠키 가져오기
Cookie[] allCookie = request.getCookies();

if (allCookie != null) { // NullPointerException 방지
    for (Cookie c : allCookie) {
        // 쿠키의 별칭(Name)과 값(Value) 출력
        out.println(c.getName() + " : " + c.getValue());
    }
}

// 특정 쿠키 무효화 (삭제)
// 삭제를 원할 경우 유효 기간을 0으로 설정하여 다시 응답에 추가합니다.
if (allCookie != null) {
    for (Cookie c : allCookie) {
        c.setMaxAge(0); // 즉시 만료
        c.setPath("/"); // 생성 시 경로와 일치해야 확실히 삭제됨
        response.addCookie(c);
    }
}
```

## 4. 주요 ServletAPI 정리

### 4.1 `HttpServlet`

* HTTP 프로토콜의 완벽한 구현

* 표준 메서드 제공 및 재정의

    * 표준 방식인 GET, POST 등에 대응하는 메서드를 제공

    * 메서드 바디만 재정의하면 됨

* 컨테이너에 의한 선별적 호출

    * 개발자가 직접 메서드를 호출하는 코드를 작성할 필요가 없음

    * Tomcat 컨테이너가 요청 확인 후, doGet 또는 doPost를 자동 호출

* 상속의 이점

    * 개발이 매우 쉬워짐

    * 비즈니스 서비스 로직 개발에만 집중

* 메소드

	* `doGet()`
    
    * `doPost()`

### 4.2 `HttpServletRequest`

* HTTP 통신을 통해 접속한 클라이언트의 모든 요청 정보를 담고 있는 객체

* 생성 시점: 클라이언트가 요청을 보낼 때마다 Tomcat에 의해 자동으로 생성되어 서블릿의 doGet 또는 doPost 메서드로 전달

* 클라이언트가 입력한 데이터, IP, 쿠키 등

* 클라이언트의 각 요청당 1:1로 독립적인 객체가 생성

* 메소드

	* `setAttribute()`

	* `getAttribute()`

	* `getRequestDispatcher()`

	* `getSession()`

	* `Cookie[] getCookies()`

### 4.3 `HttpServletResponse`

* 클라이언트 브라우저에게 응답을 전달하기 위한 정보를 보유하고 관리하는 객체

* 클라이언트가 접속할 때마다 Tomcat에 의해 자동으로 생성되어 서블릿의 실행 메서드로 전달

* 메소드

	* `setContentType("client응답포멧;인코딩설정")`

	* `PrintWriter getWriter()`

	* `sendRedirect()`

	* `addCookie()`
	
### 4.4 `HttpSession`

* 클라이언트의 상태 정보를 서버 측 메모리에 저장하여 관리하는 객체

* 페이지 이동 방식과 무관하게 데이터가 안정적으로 유지

* 메소드

	* `getId()`

	* `setAttribute()`

	* `getAttribute()`

	* `invalidate()`
	
### 4.5 `Cookie`

* 클라이언트 시스템에 상태 유지 정보를 저장

* 메소드

	* `new Cookie("별칭, "값")`

	* `setMaxAge(초단위)`

	* `getName()`

	* `getValue()`

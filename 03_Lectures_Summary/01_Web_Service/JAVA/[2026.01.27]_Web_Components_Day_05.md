# Web Components Day 05

## 1. JavaScript (JS)

브라우저 내에서 실행되어 동적인 페이지를 만드는 Client-side Script 언어입니다.

* 실행 환경의 확장 (Node.js)

    * 서버에 실행 환경을 설치하여 JS 문법으로 Backend 개발이 가능하게 한 기술입니다.

    * 비동기 I/O 처리에 강점이 있어 가벼운 웹 서버나 실시간 채팅 서버 구축에 자주 활용됩니다.

## 2. JavaScript 기본 문법

### 2.1 변수

자바스크립트는 변수 선언 시 타입을 명시하지 않는 동적 타이핑 언어입니다. 대입되는 데이터에 따라 타입이 유동적으로 결정됩니다.

#### 선언 키워드 및 유효 범위

* 키워드 없이 선언 (`variable = value`)

    * 함수 내부에서 선언하더라도 전역 변수로 간주됩니다.

    * 의도치 않은 데이터 오염을 발생시키므로 절대 사용을 권장하지 않는 방식입니다.

* `var`

    * 함수 레벨 스코프 (Function Scope): 함수 내부 어디서든 접근 가능합니다.

    * JS 문법 생성시점에 제시된 키워드입니다.

* `let`

    * 블록 레벨 스코프 (Block Scope): `if`, `for`, `while` 등 중괄호(`{ }`) 블록 내에서만 유효합니다.

    * 사용 범위를 명확히 제한하여 오류를 줄여주므로 `var` 대신 적극 사용을 권장합니다.

* `const`

    * 상수: 한 번 할당하면 값을 변경할 수 없습니다.

    * 성능 최적화: 값이 변하지 않음을 보장하므로 실행 속도와 메모리 관리 면에서 이점이 있습니다. 값이 불변인 경우 최우선으로 사용합니다.

### 2.2 함수와 메소드

| 구분 | 설명 | 언어별 특징 |
| --- | --- | --- |
| 메소드 | Class 또는 객체(Object) 내부에서 구현되는 기능을 지칭합니다. | Java: 모든 기능이 Class 내부에 구현되므로 전부 메소드입니다. |
| 함수 | Class와 무관하게 독립적으로 개발되어 호출 가능한 기능을 지칭합니다. | JS/Python: 독립적인 함수와 객체 소속의 메소드가 공존합니다. |

### 2.3 객체 타입

* 브라우저 내장 객체 (Built-in Objects)

    * `window`: 브라우저 창 전체를 제어 (BOM)

    * `document`: HTML 문서 구조를 제어 (DOM)

    * `console`, `location` 등

* 표준 내장 객체 (Native Objects)

    * JS 언어 자체에서 제공하는 객체: `Array`, `Date`, `Math`, `JSON` 등

* 사용자 정의 객체

    * 개발자가 `class` 문법이나 객체 리터럴(`{ }`)을 사용하여 직접 정의한 타입입니다.

## 3. DOM (Document Object Model)

DOM은 브라우저가 HTML 문서를 트리 구조로 객체화한 것입니다. 자바스크립트는 이 DOM API를 통해 HTML 요소의 내용, 스타일, 속성을 동적으로 제어합니다.

* 코드 예시

    ```HTML
    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>js3DOM.html</title>
    </head>
    <body>

        <h3>DOM API</h3>
        <br><hr><br>

        1. input tag 두개 / button 클릭시 input tag 데이터값 이동 <br>
        <input type="text" name="" id="iOne" value="초기데이터"> -
        <input type="text" name="" id="iTwo">
        <br>
        <button id="btn1">1번 데이터 이동</button>

        <script>
            document.getElementById("btn1").addEventListener("click", mtFun1);
            /* 로직 흐름 분석:
            1. 버튼(btn1)을 클릭하면 mtFun1 함수를 실행
            2. iOne에 입력된 값(value)을 가져와서 변수에 담거나 직접 iTwo의 값으로 대입
            3. 이동 후 iOne은 빈 문자열("")로 초기화
            */
            function mtFun1() {
                const input1 = document.getElementById("iOne");
                const input2 = document.getElementById("iTwo");

                input2.value = input1.value; // 데이터 복사
                input1.value = "";           // 원본 삭제
    }
        </script>

    </body>
    </html>
    ```

## 5. 비동기 개발 기술 (AJAX)

### 5.1 핵심 기술 `XMLHttpRequest` 객체

웹 페이지 전체를 다시 로드하지 않고도, 백그라운드에서 서버와 데이터를 주고받을 수 있게 해주는 브라우저 내장 객체입니다.

* 핵심 이점: 페이지 이동이나 리프레시 없이 필요한 데이터만 서버에 요청하여 화면의 일부만 갱신

* 단일 객체 운용: 하나의 XMLHttpRequest 객체가 요청 전송부터 응답 수신, 상태 모니터링까지 전 과정을 관리합니다.

### 5.2 통신을 위해 필요한 요소

* HTTP 통신 규약: 요청의 성격에 맞는 방식 선택 (GET, POST, PUT, DELETE 등)

* 대상 서버 정보: 어느 서버의 어떤 프로그램 (URL)에 요청을 보낼 것인가?

* 진행 상태 파악: 현재 요청이 전송 중인지, 응답이 도착했는지 단계별 상태 확인 (readyState)

* 응답 결과 판별: 서버가 보내온 응답이 성공인지 에러인지 상태 코드 확인 (status)

    * 정상: 200

    * 비정상: 404 405 500

### 5.3 동작 방식

* Create: new XMLHttpRequest() 객체 생성

* Define Callback: 응답이 왔을 때 실행할 함수 (Callback Function)를 정의

    * `xhttp.onreadystatechange = function() { ... }`

* Open: 요청 정보 설정

    * `xhttp.open("GET", "url", true);` (마지막 인자 true는 비동기 방식을 의미)

* Send: 서버로 요청을 실제 전송

    * `xhttp.send();`

### 5.4 코드 예시

* GET

    ```Javascript
    function reqRes() {
        const xhttp = new XMLHttpRequest();
        
        // 1. 응답 처리 로직 (Callback)
        xhttp.onreadystatechange = function() {
            // 요청 완료(4) 및 성공(200) 확인
            if (this.readyState == 4 && this.status == 200) {
                // 서버의 응답은 항상 '문자열'이므로 JSON 객체로 변환(Parsing) 필수
                let resData = JSON.parse(xhttp.responseText);
                
                // 계층 구조를 따라 특정 데이터에 접근
                console.log("이순신 이름 추출:", resData.people[1].name);
            }
        };
        
        // 2. 요청 설정 및 전송
        xhttp.open("GET", "reqResAjaxTest2.jsp"); // 데이터가 URL에 노출되는 방식
        xhttp.send();
    }
    ```

* POST

    ```Javascript
    function reqRes2() {
        const xhttp = new XMLHttpRequest();
        
        xhttp.onreadystatechange = function() {
            if (this.readyState == 4 && this.status == 200) {
                let resData = xhttp.responseText;
                alert("서버 응답: " + resData);
            }
        };

        // 1. 요청 정보 설정 (POST)
        xhttp.open("POST", "reqResAjaxTest3.jsp");
        
        /* 2. POST 방식 필수 설정
        * 본문에 데이터를 담아 보낼 때는 데이터의 형식(MIME Type)을 반드시 서버에 알려야 함
        * application/x-www-form-urlencoded: 일반적인 HTML Form 데이터 형식
        */
        xhttp.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
        
        // 3. 실제 데이터 전송 (send 메서드의 인자로 전달)
        let sendMsg = "msg=" + document.getElementById("inputData").value;
        xhttp.send(sendMsg);
    }
    ```

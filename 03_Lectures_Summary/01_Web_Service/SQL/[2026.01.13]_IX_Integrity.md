# SQL Integrity Practice

## 0. 사전 개념 정리

### 0.1 데이터 강제 사항 종류 (Constraints & Structure)

테이블 설계 시 다음과 같은 요소들을 통해 데이터를 제어합니다.

1. Table: 데이터를 저장하는 기본 단위 결정

2. 컬럼 (Column): 저장할 정보의 항목 정의

3. 컬럼 크기 (Size): 저장될 데이터의 최대 길이 제한 (예: `VARCHAR2(20)`)

4. 컬럼 타입 (Type): 데이터 형식 지정 (문자, 숫자, 날짜 등)

5. 중복 허용 여부 (Unique): 동일한 데이터의 중복 입력 방지

6. NULL 허용 여부 (NOT NULL): 필수 입력 필드 지정

7. 기본 값 (Default): 데이터 미입력 시 자동으로 채워질 값 설정

### 0.2 Primary Key (PK, 기본키)

* 테이블에서 각 행 (Row)을 유일하게 식별할 수 있는 식별자입니다.

* 제약 조건: 중복을 허용하지 않으며 (Unique), NULL 값을 허용하지 않습니다 (Not Null).

* 테이블당 오직 하나의 Primary Key만 설정할 수 있습니다.

### 0.3 Foreign Key (FK, 외래키/참조키)

* 다른 테이블의 Primary Key를 참조하는 컬럼입니다.

* 관계 형성: 테이블 간의 주종 관계(부모-자식 관계)를 형성합니다.

* 부모 테이블: PK를 보유하고 있으며 데이터를 제공하는 테이블

* 자식 테이블: FK를 통해 부모 테이블의 PK를 참조하는 테이블

* 참조 무결성: 자식 테이블은 부모 테이블에 존재하는 값만 가질 수 있거나, NULL 값을 가질 수 있습니다.

## 1. 제약 조건 설정 방법

### 1.1 테이블 생성 시 설정

* Oracle

    ```SQL
    -- 컬럼 레벨: 간결한 설정 (자동 이름 부여)
    CREATE TABLE emp01(
        empno number(4) PRIMARY KEY,
        ename varchar2(20) NOT NULL
    );

    -- 테이블 레벨: CONSTRAINT 키워드로 이름 명시 권장
    CREATE TABLE emp04(
        empno NUMBER(4),
        ename VARCHAR2(20) NOT NULL,
        deptno NUMBER(4),
        CONSTRAINT emp04_empno_pk PRIMARY KEY (empno),
        CONSTRAINT emp04_deptno_fk FOREIGN KEY (deptno) REFERENCES dept(deptno)
    );
    ```

* MySQL

    ```SQL
    -- 컬럼 레벨: 간결한 설정 (자동 이름 부여)
    CREATE TABLE emp01(
        empno INT PRIMARY KEY,
        ename VARCHAR(20) NOT NULL
    );

    -- 테이블 레벨: CONSTRAINT 키워드로 이름 명시 권장
    CREATE TABLE emp04(
        empno INT,
        ename VARCHAR(20) NOT NULL,
        deptno INT,
        CONSTRAINT emp04_empno_pk PRIMARY KEY (empno),
        CONSTRAINT emp04_deptno_fk FOREIGN KEY (deptno) REFERENCES dept(deptno)
    );
    ```

### 1.2 기존 테이블에 추가 및 수정

* Oracle & MySQL

    ```SQL
    -- PK 제약 조건 추가
    ALTER TABLE emp03 ADD CONSTRAINT emp03_pk_empno PRIMARY KEY (empno);

    -- FK 제약 조건 추가: dept 테이블의 deptno 참조
    ALTER TABLE emp04 ADD CONSTRAINT fk_emp04_empno FOREIGN KEY (deptno) REFERENCES dept(deptno);

    -- CHECK 제약 조건 추가: 성별 데이터 유효성 검증 
    ALTER TABLE emp06 ADD CHECK (gender IN ('F', 'M'));
    ```

* Oracle

    ```SQL
    -- DEFAULT 수정
    ALTER TABLE emp06 MODIFY (age DEFAULT 1);

    -- 제약 조건 삭제: PK 삭제 또는 이름으로 삭제
    ALTER TABLE emp03 DROP PRIMARY KEY;
    ALTER TABLE emp04 DROP CONSTRAINT EMP04_EMPNO_PK;
    ```

* MySQL

    ```SQL
    -- DEFAULT 수정
    ALTER TABLE emp06 ALTER COLUMN age SET DEFAULT 1;

    -- 제약 조건 삭제: PK 삭제 또는 이름으로 삭제
    -- 제약 조건명으로 삭제 시 종류 명시 필요
    ALTER TABLE emp03 DROP PRIMARY KEY;
    ALTER TABLE emp04 DROP FOREIGN KEY fk_emp04_empno;
    ```

## 2. 제약 조건별 핵심 실습

### 2.1 PRIMARY KEY (기본키) & UNIQUE (고유키)

* Oracle

    ```SQL
    -- 테이블 레벨에서 제약 조건명 명시
    CREATE TABLE emp03(
        empno NUMBER(4),
        ename VARCHAR2(20) NOT NULL,
        CONSTRAINT pk_empno_emp03 PRIMARY KEY (empno)
    );

    CREATE TABLE emp02(
        empno number(4) PRIMARY KEY,
        ename varchar2(20) UNIQUE
    );
    ```

* MySQL

    ```SQL
    -- 테이블 레벨에서 제약 조건명 명시
    CREATE TABLE emp03(
        empno INT,
        ename VARCHAR(20) NOT NULL,
        CONSTRAINT pk_empno_emp03 PRIMARY KEY (empno)
    );

    CREATE TABLE emp02(
        empno INT PRIMARY KEY,
        ename VARCHAR(20) UNIQUE
    );
    ```

### 2.2 FOREIGN KEY (외래키)

* Oracle

    ```SQL
    -- 테이블 생성 시 설정
    -- empno는 PK / deptno는 dept 테이블의 deptno를 참조
    CREATE TABLE emp04(
        empno NUMBER(4),
        ename VARCHAR2(20) NOT NULL,
        deptno NUMBER(4),
        CONSTRAINT emp04_empno_pk PRIMARY KEY (empno),
        CONSTRAINT emp04_deptno_fk FOREIGN KEY (deptno) REFERENCES dept(deptno)
    );

    -- ALTER 명령어로 제약 조건 추가
    -- 기존에 존재하는 emp04 테이블의 deptno에 외래키 설정
    ALTER TABLE emp04 ADD CONSTRAINT fk_emp04_empno FOREIGN KEY (deptno) REFERENCES dept(deptno);
    ```

* MySQL

    ```SQL
    -- 테이블 생성 시 설정
    -- empno는 PK / deptno는 dept 테이블의 deptno를 참조
    CREATE TABLE emp04(
        empno INT,
        ename VARCHAR(20) NOT NULL,
        deptno INT,
        CONSTRAINT emp04_empno_pk PRIMARY KEY (empno),
        CONSTRAINT emp04_deptno_fk FOREIGN KEY (deptno) REFERENCES dept(deptno)
    );

    -- ALTER 명령어로 제약 조건 추가
    -- 기존에 존재하는 emp04 테이블의 deptno에 외래키 설정
    ALTER TABLE emp04 ADD CONSTRAINT fk_emp04_empno FOREIGN KEY (deptno) REFERENCES dept(deptno);
    ```

### 2.3 CHECK & DEFAULT

* Oracle

    ```SQL
    -- 0~99 범위 내의 나이만 저장 가능하도록 설정
    CREATE TABLE emp05 (
        empno NUMBER(4) PRIMARY KEY,
        ename VARCHAR2(20) NOT NULL,
        age NUMBER(2),
        CHECK (age BETWEEN 0 AND 99)
    );

    -- 성별 컬럼에 'M' 또는 'F'만 허용
    CREATE TABLE emp06(
        empno NUMBER($),
        ename VARCHAR2(10) NOT NULL,
        gender CHAR(1),
        CHECK (gender IN ('M', 'F'))
    );

    -- 나이 입력 생략 시 기본값 1 저장
    CREATE TABLE emp06(
        empno NUMBER(4),
        ename VARCHAR2(10) NOT NULL,
        age NUMBER(3) DEFAULT 1
    );

    -- 기존 테이블의 컬럼을 DEFAULT 1로 수정
    ALTER TABLE emp06 MODIFY (age DEFAULT 1);
    ```

* MySQL

    ```SQL
    -- 0-99 범위 내의 나이만 저장 가능하도록 설정
    CREATE TABLE emp05 (
        empno INT PRIMARY KEY,
        ename VARCHAR(20) NOT NULL,
        age INT,
        CHECK (age BETWEEN 0 AND 99)
    );

    -- 나이 입력 생략 시 기본값 1 저장
    CREATE TABLE emp06(
        empno INT,
        ename VARCHAR(10) NOT NULL,
        age INT DEFAULT 1
    );

    -- 기존 테이블의 컬럼을 DEFAULT 1로 수정
    ALTER TABLE emp06 ALTER COLUMN age SET DEFAULT 1;
    ```

## 3. 제약 조건 관리 (조회 및 삭제)

### 3.1 정보 조회

* Oracle

    ```SQL
    -- 제약 조건 이름(NAME), 종류(TYPE), 테이블 명 조회
    -- 테이블 명은 반드시 대문자
    SELECT CONSTRAINT_NAME, CONSTRAINT_TYPE, TABLE_NAME 
    FROM user_constraints
    WHERE TABLE_NAME = 'EMP06';
    ```

* MySQL

    ```SQL
    -- 특정 테이블의 제약 조건 정보 조회
    SELECT * FROM information_schema.TABLE_CONSTRAINTS 
    WHERE TABLE_NAME = 'emp06';
    ```

### 3.2 제약 조건 삭제

* Oracle

    ```SQL
    -- 기본키(Primary Key) 삭제
    ALTER TABLE emp03 DROP PRIMARY KEY;

    -- 제약 조건명으로 삭제
    ALTER TABLE emp04 DROP CONSTRAINT EMP04_EMPNO_PK;

    -- DEFAULT 제약 조건 삭제 (NULL로 변경하여 속성 제거)
    ALTER TABLE emp06 MODIFY (age DEFAULT NULL);
    ```

* MySQL

    ```SQL
    -- Primary Key 삭제
    ALTER TABLE emp03 DROP PRIMARY KEY;

    -- Foreign Key 삭제 (제약 조건 종류 명시 필수)
    ALTER TABLE emp04 DROP FOREIGN KEY emp04_deptno_fk;

    -- DEFAULT 제약 조건 삭제
    ALTER TABLE emp06 ALTER age DROP DEFAULT;
    ```

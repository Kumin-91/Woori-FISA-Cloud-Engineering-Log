# SQL SELECT Group Practice

## 1. 집계 함수

* Oracle & MySQL

    ```SQL
    -- 10번 부서에 속한 사원들의 급여 (sal) 합
    SELECT SUM(sal) FROM emp WHERE deptno = 10;
    -- 10번 부서에 속한 사원들의 급여 (sal) 최대
    SELECT MAX(sal) FROM emp WHERE deptno = 10;
    -- 10번 부서에 속한 사원들의 급여 (sal) 최소
    SELECT MIN(sal) FROM emp WHERE deptno = 10;
    -- 10번 부서에 속한 사원들의 급여 (sal) 평균
    SELECT AVG(sal) FROM emp WHERE deptno = 10;
    -- 10번 부서에 속한 최고 급여의 직원 이름과 급여를 검색
    SELECT ename, sal FROM emp
    WHERE sal = (SELECT MAX(SAL) FROM emp);
    ```

* 일반 단순 컬럼은 그룹함수와 동시 조회 불가

* 집계 함수는 결과가 1행이지만, 일반 컬럼은 여러 행이라 매칭되지 않아 에러 발생

    ```SQL
    -- 모든 직원명과 직원수를 검색
    SELECT ename, COUNT(*) FROM emp;
    -- 부서별 커미션 받는 직원 수
    SELECT deptno, COUNT(comm) FROM emp;
    ```

## 2. `GROUP BY` & `HAVING`

### 2.1 `GROUP BY` 기본

* Oracle & MySQL

    ```SQL
    -- 부서별 커미션(comm)을 받는 직원 수 (comm이 NULL이면 제외됨)
    SELECT deptno, COUNT(comm)
    FROM emp GROUP BY deptno;
    ```

### 2.2 실행 순서와 별칭 (Alias) 사용

* 표준 실행 순서: `FROM` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY`

* Oracle 23c+ & MySQL: 별칭 사용 가능

    ```SQL
    SELECT deptno, ROUND(AVG(sal)) AS "평균급여"
    FROM emp GROUP BY deptno
    HAVING "평균급여" >= 2000;
    ```

* Oracle (Prior to 23c): `SELECT` 절에서 지정한 별칭을 `GROUP BY`나 `HAVING`에서 사용 불가

    ```SQL
    -- inline view
    SELECT *
    FROM (SELECT deptno, ROUND(AVG(sal)) AS 평균급여
    	  FROM emp GROUP BY deptno)
    WHERE "평균급여" >= 2000;
    ```

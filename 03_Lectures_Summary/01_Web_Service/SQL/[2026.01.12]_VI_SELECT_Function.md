# SQL SELECT Function

### 1. 숫자함수

### 1.1 절대값

* Oracle & MySQL (`FROM dual`) 생략 가능

    ```SQL
    SELECT 3.5, -3.5, +3.5,
    ABS(3.5), ABS(-3.5), ABS(+3.5) FROM dual;
    ```

### 1.2 반올림

* Oracle & MySQL (`FROM dual`) 생략 가능

    ```SQL
    SELECT 3.5, -3.5, +3.5,
    ROUND(3.5), ROUND(-3.5), ROUND(+3.5) FROM dual; 
    ```

### 1.3 자리수 버리기

* Oracle

    ```SQL
    SELECT 3.5, -3.5, +3.5
    TRUNC(3.5), TRUNC(-3.5), TRUNC(+3.5) FROM dual; 
    ```

* MySQL

    ```SQL
    -- 자리수 명시 필수
    SELECT 3.5, -3.5, +3.5
    TRUNCATE(3.5, 0), TRUNCATE(-3.5, 0), TRUNCATE(+3.5, 0) FROM dual; 
    ```

## 1.4 나눗셈 나머지 값

* Oracle

    ```SQL
    SELECT MOD(10, 3) FROM dual;
    ```

* MySQL

    ```SQL
    SELECT MOD(10, 3);
    SELECT 10 % 3;
    ```

## 2. 문자함수

### 2.1 대소문자

* Oracle

    ```SQL
    SELECT UPPER('oRaClE'), LOWER('oRaClE') FROM dual;
    ```

* MySQL

    ```SQL
    SELECT UPPER('oRaClE'), LOWER('oRaClE');
    ```

    * MySQL에서는 데이터값의 대소문자 구분없이 검색

    * 해결책 1

        ```SQL
        SELECT job FROM emp
        WHERE job = BINARY('manager');
        ```

    * 해결책 2: table 구조 수정 (DDL)

        ```SQL
        ALTER TABLE emp CHANGE job
        job VARCHAR(20) BINARY;
        ```

### 2.2 문자열 길이

* Oracle

    ```SQL
    -- 문자열의 길이
    SELECT lENGTH(ename), ename FROM emp;
    SELECT LENGTH(dname), dname FROM dept;
    -- 문자열 byte 길이
    SELECT lENGTHB(ename), ename FROM emp;
    SELECT LENGTHB(dname), dname FROM dept;
    ```

* MySQL

    ```SQL
    -- 문자열의 길이 (Oracle - LENGTH)
    SELECT CHARACTER_LENGTH(ename), ename FROM emp;
    SELECT CHARACTER_LENGTH(dname), dname FROM dept;
    -- 문자열 byte 길이 (Oracle - LENGTHB)
    SELECT lENGTH(ename), ename FROM emp;
    SELECT LENGTH(dname), dname FROM dept;
    ```

### 2.3 문자열 일부 추출

* Oracle & MySQL

    ```SQL
    SELECT dname, SUBSTR(dname, 1, 2) FROM dept;
    ```

### 2.5 - 여백 제거

* Oracle & MySQL (`FROM dual`) 생략 가능

    ```SQL
    SELECT ' abc ',
           LENGTH(' abc '), 
	       TRIM(' abc '),
           LENGTH(TRIM(' abc '))
    FROM dual;
    ```

## 3. 날짜함수

## 3.1 현재 시간

* Oracle

    ```SQL
    -- SYSDATE는 초 단위까지 포함하는 서버 시간
    UPDATE emp01 SET hiredate = sysdate;
    ```

* MySQL

    ```SQL
    -- NOW(): 날짜 + 시간, CURDATE(): 날짜만
    UPDATE emp01 SET hiredate = NOW();
    ```

### 3.2 날짜 추출

* Oracle

    ```SQL
    -- 년도만 검색
    SELECT hiredate, TO_CHAR(hiredate, 'yyyy') FROM emp;
    -- 월만 검색
    SELECT hiredate, TO_CHAR(hiredate, 'mm') FROM emp;
    -- 일만 검색
    SELECT hiredate, TO_CHAR(hiredate, 'dd') FROM emp;
    ```

* MySQL

    ```SQL
    -- 년도만 검색
    SELECT hiredate, DATE_FORMAT(hiredate, '%Y') FROM emp;
    -- 월만 검색
    SELECT hiredate, DATE_FORMAT(hiredate, '%m') FROM emp;
    -- 일만 검색
    SELECT hiredate, DATE_FORMAT(hiredate, '%d') FROM emp;
    ```

### 3.3 날짜타입 비교

* Oracle

    ```SQL
    -- date 타입을 문자열로 가공 후 비교 (권장)
    SELECT ename, hiredate FROM emp
    WHERE TO_CHAR(hiredate, 'MM') = '02';
    ```

* MySQL

    ```SQL
    -- 방법 1 (함수 이용)
    WHERE MONTH(hiredate) = 2;
    -- 방법 2 (포맷 이용)
    WHERE DATE_FORMAT(hiredate, '%m') = '02';
    ```

## 4. 조건식 함수

### 4.1 조건식

* Oracle : 크다/작다 같은 범위 비교 불가

    ```SQL
    -- 10번 부서는 A로 검색/20번 부서는 B로 검색/그외 무로 검색
    SELECT DECODE(deptno, 10, 'A',
                          20, 'B',
                              '무') FROM dept;
    -- job이 ANALYST 5%인상(sal*1.05), SALESMAN 은 10%(sal*1.1) 인상, 
    -- MANAGER는 15%(sal*1.15), CLERK 20%(sal*1.2) 인상
    SELECT job, sal, DECODE(job, 'ANALYST', sal * 1.05,
                                 'SALESMAN', sal * 1.1,
                                 'MANAGER', sal * 1.15,
                                 'CLERK', sal * 1.2,
                                 sal) AS "SAL_UP" FROM emp;
    ```

* Oracle & MySQL

    ```SQL
    -- 단순 비교
    SELECT ename, job FROM emp;
    SELECT ename, job,
    	CASE job
    		WHEN 'MANAGER' THEN "갑"
    		WHEN 'ANALYST' THEN "을"
    		ELSE "병"
    	END AS "직무" FROM emp;
    -- 범위 비교
    SELECT ename, sal,
       CASE 
           WHEN sal >= 3000 THEN '고급'
           WHEN sal >= 1500 THEN '중급'
           ELSE '초급'
       END AS 등급 FROM emp;
    ```

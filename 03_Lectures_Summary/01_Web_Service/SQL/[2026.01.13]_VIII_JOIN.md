## 1. 동등 조인 (Equi-Join)

* 조인 연산자 (=)를 사용하여 두 테이블의 공통 컬럼 값이 정확히 일치하는 데이터를 연결

* 두 테이블 간에 공통 데이터가 존재하는 행만 결과로 반환

* Oracle & MySQL

    ```SQL
    -- SMITH의 이름(ename), 사번(empno), 근무지역(loc) 정보를 검색
    -- 이름과 사번은 emp 테이블에, 근무지역은 dept 테이블에 존재
    SELECT ename, empno, loc
    FROM emp, dept
    WHERE ename = 'SMITH' and emp.deptno = dept.deptno;
    ```

    ```SQL
    -- 주의: 테이블 별칭 부여 시 'AS' 키워드를 사용하지 않음
    -- 뉴욕('NEW YORK')에 근무하는 사원의 이름(ename)과 급여(sal)를 검색 
    SELECT e.ename, e.sal
    FROM emp e, dept d
    WHERE e.deptno = d.deptno AND d.loc = 'NEW YORK';
    ```

## 2. 비동등 조인 (Non-Equi Join)

* 조인 조건이 특정 값과 100% 일치하지 않고, 부등호 (>, <, >=, <=)나 특정 범위 내에 있는지 비교할 때 사용

* Oracle & MySQL

    ```SQL
    -- 사원의 급여가 몇 등급인지 검색
    -- 사원의 이름(ename), 급여(sal)가 어느 등급(grade)에 속하는지 검색
    -- BETWEEN 연산자는 'sal >= losal AND sal <= hisal'과 동일하게 작동
    SELECT e.ename, e.sal, s.grade
    FROM emp e, salgrade s
    WHERE e.sal BETWEEN s.losal AND s.hisal;
    ```

## 3. 셀프 조인 (Self Join)

* 동일한 테이블을 별칭을 사용하여 마치 두 개의 테이블인 것처럼 조인하는 방식

* 주로 조직도 (사원-관리자), 카테고리 계층, 또는 동일한 속성을 가진 그룹 내 비교 시 사용

* 주의: 동일 테이블을 참조하므로 컬럼 혼동을 막기 위해 테이블 별칭 사용이 필수

* Oracle & MySQL

    ```SQL
    -- 관리자(Manager) 이름이 'KING'인 사원들의 이름과 직무 검색
    -- e: 사원(Employee) 테이블 역할, m: 관리자(Manager) 테이블 역할
    SELECT e.ename, e.job
    FROM emp e, emp m
    WHERE e.mgr = m.empno             -- 조인 조건: 사원의 관리자 번호 = 관리자의 사번
        AND m.ename = 'KING';         -- 필터 조건: 관리자 이름이 KING
    ```

    ```SQL
    -- 'SMITH'와 동일한 부서에서 근무하는 동료 사원의 이름 검색 (SMITH 본인 제외)
    -- my: SMITH의 정보, you: 동료의 정보
    -- 부정 연산자 지원: != , <> , NOT (컬럼 = '값')
    SELECT you.ename
    FROM emp my, emp you
    WHERE my.deptno = you.deptno      -- 조인 조건: 부서 번호가 동일함
        AND my.ename = 'SMITH'        -- 기준: 내 이름이 SMITH
        AND you.ename <> 'SMITH';     -- 제외: 동료 이름에서 내 이름은 뺌
    ```

## 4. 외부 조인 (Outer Join)

* 조인 조건이 불충분 (데이터가 한쪽 테이블에 존재하지 않음)해도 결과에서 누락시키지 않고 검색하는 방식

* 특정 컬럼이 NULL인 데이터나 조인 상대가 없는 행을 결과에 포함하고자 할 때 사용

* Q: 모든 사원명과 메니저명 검색, 사원 (KING)은 상사 (mgr)가 NULL이어서 일반적인 조인시 결과에서 제외

    * Oracle & MySQL
    
        ```SQL
        --KING의 상사가 없어 사원명에 KING 검색 누락
        SELECT e.ename AS 사원명, m.ename AS 매니저
        FROM emp e, emp m
        WHERE e.mgr = m.empno;
        ```

        ```SQL
        -- 사원(e) 쪽의 모든 행을 유지하기 위해 LEFT JOIN 사용
        SELECT e.ename AS 사원명, m.ename AS 매니저
        FROM emp e LEFT JOIN emp m 
            ON e.mgr = m.empno;
        ```
    
    * Oracle
    
        ```SQL
        -- 데이터가 부족한(NULL을 매칭해야 할) 'm.empno' 쪽에 (+)를 표시
        SELECT e.ename AS 사원명, m.ename AS 매니저
        FROM emp e, emp m 
        WHERE e.mgr = m.empno(+);
        ```

* Q. 모든 직원명 (ename), 부서번호 (deptno), 부서명 (dname) 검색

    * Oracle

        ```SQL
        -- 40번 부서(OPERATIONS)에는 소속된 사원이 없으므로 일반 조인 시 검색되지 않음
        SELECT e.ename, e.deptno, d.dname
        FROM emp e, dept d
        WHERE e.deptno(+) = d.deptno;
        ```

* Q. 모든 부서 정보를 출력하되, 사원 정보는 급여 3000 이상인 경우만 출력

    * Oracle & SQL

        ```SQL
        -- Right Join 사용
        SELECT d.deptno, dname, loc, empno, ename, job, mgr, hiredate, sal, comm
        FROM emp e RIGHT JOIN dept d
            ON e.deptno = d.deptno AND sal >= 3000;
        -- Left Join 사용
        SELECT d.deptno, dname, loc, empno, ename, job, mgr, hiredate, sal, comm
        FROM dept d LEFT JOIN emp e
            ON e.deptno = d.deptno AND sal >= 3000;
        ```

    * Oracle

        ```SQL
        -- 조인 조건 외의 추가 필터 조건에도 (+)를 붙여야 Outer Join이 유지
        SELECT d.deptno, dname, loc, empno, ename, job, mgr, hiredate, sal, comm
        FROM emp e, dept d
        WHERE e.deptno(+) = d.deptno AND e.sal(+) >= 3000;
        ```

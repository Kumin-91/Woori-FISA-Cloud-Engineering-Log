# About ElasticStack

## 1. ElasticStack이란?

* Elasticsearch를 중심으로 Logstash, Kibana, Beats 등 여러 오픈소스 도구들이 모여 데이터를 수집, 분석, 시각화하는 통합 플랫폼입니다.

* 분산형 환경에서 대용량 데이터를 실시간에 가깝게 검색하고 분석할 수 있어, 로그 분석 및 전문 검색에 특화되어 있습니다.

## 2. ElasticStack 주요 기능

### 2.1 Elasticsearch

* 데이터를 저장하고 검색/분석하는 역할을 하는 분산형 검색 엔진입니다.

* Apache Lucene 라이브러리를 기반으로 구축되었습니다.

### 2.2 Kibana

* Elasticsearch에 저장된 데이터를 차트, 그래프 등으로 시각화하고 스택 전체를 관리하는 대시보드입니다.

### 2.3 Logstash

* 다양한 소스에서 데이터를 수집하여 변환한 뒤 Elasticsearch로 전송하는 데이터 파이프라인입니다.

### 2.4 FileBeats

* 서버의 로그 파일을 실시간으로 읽어 전송하는 경량 수집기입니다.

* Logstash보다 리소스를 적게 소모하여 에이전트로 널리 쓰입니다.

## 3. ElasticStack의 Flow

데이터는 일반적으로 다음과 같은 경로를 거쳐 사용자에게 보여집니다

* **수집 (Beats):** 각 서버의 로그나 메트릭을 수집합니다.

* **가공 (Logstash):** 수집된 데이터를 분석하기 좋은 형태로 파싱하거나 필터링합니다.

* **저장/검색 (Elasticsearch):** 가공된 데이터를 인덱싱하여 저장하고 검색 엔진을 통해 빠르게 탐색할 수 있게 합니다.

* **시각화 (Kibana):** 검색 결과를 사용자가 이해하기 쉬운 대시보드로 구성합니다.

## 4. Elasticsearch 구조 및 용어 이해하기

### 4.1 RDBMS와의 용어 비교

| Elasticsearch (NoSQL) | RDBMS (Oracle/MySQL) | 설명 |
| --- | --- | --- |
| Index | Database / Table | 데이터가 저장되는 가장 큰 단위입니다. |
| Document | Row | JSON 형식으로 저장되는 하나의 데이터 단위입니다. |
| Field | Column | 데이터가 가진 속성을 나타냅니다. |
| Mapping | Schema | 필드의 데이터 타입을 정의하는 규칙입니다. |

* **분산 구조:** 하나의 인덱스는 여러 개의 샤드 (Shard)로 쪼개져 여러 노드 (Node)에 분산 저장되어 성능과 가용성을 높입니다.

## 5. 검색 엔진 관점에서의 ElasticSearch 특징

### 5.1 역색인 (Inverted Index)

* 책 뒷면의 찾아보기(Index)처럼, 단어를 기준으로 해당 단어가 포함된 문서의 위치를 저장하는 방식입니다.

* 수많은 문서 중에서 특정 단어가 포함된 내용을 찾을 때 RDBMS의 LIKE 검색보다 압도적으로 빠릅니다.

### 5.2 거의 실시간 (Near Real-Time, NRT)

* 데이터가 색인된 후 검색이 가능해지기까지 약 1초 정도의 지연이 발생하지만, 일반적인 서비스에서는 실시간처럼 느껴집니다.

### 5.3 Schemaless 및 RESTful API

* 엄격한 스키마 정의 없이 JSON 문서를 던지면 자동으로 필드를 생성합니다.

* 모든 명령을 HTTP 프로토콜의 REST API로 처리하여 개발 언어에 상관없이 쉽게 연동할 수 있습니다.

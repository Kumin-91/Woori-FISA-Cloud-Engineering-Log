## 1. 사용자와 그룹

### 1.1 사용자 관리

```bash
# 모든 사용자 정보 확인
cat /etc/passwd

# 특정 그룹에 속한 사용자 확인
getent group <GROUP_NAME>

# 홈 디렉토리 생성과 함께 사용자 추가
sudo adduser <USER_NAME>

# 홈 디렉토리 생성 없이 사용자 추가
sudo useradd <USER_NAME>

# 사용자 삭제
sudo deluser <USER_NAME>
```

### 1.2 그룹 관리

```bash
# 그룹 정보 확인
cat /etc/group

# 그룹 비밀번호 정보 확인
cat /etc/gshadow

# 그룹 추가
sudo groupadd <GROUP_NAME>

# 그룹 삭제
sudo groupdel <GROUP_NAME>

# 그룹에 사용자 추가
# -a: append, -G: secondary group
sudo usermod -aG <GROUP_NAME> <USER_NAME>
```

### 1.3 미션: 사용자 및 그룹 설정 실습

```bash
# 1. 사용자 3명 추가 (user01, user02, user03)
sudo adduser user01
sudo adduser user02
sudo adduser user03 

# 2. user01은 fisa 계정과 동일한 그룹으로 설정
sudo usermod -aG fisa user01

# 3. user02와 user03은 동일한 그룹으로 설정
# 먼저 새로운 그룹 생성
sudo groupadd user_group
# 그룹에 사용자들 추가
sudo usermod -aG user_group user02
sudo usermod -aG user_group user03
```

## 2. 파일의 소유와 허가권

### 2.1 파일 소유권 관리

```bash
# 소유자 (User)만 변경
chown <OWNER> <FILE_NAME>

# 그룹 (Group)만 변경
chown :<GROUP> <FILE_NAME>
# 또는
chgrp <GROUP> <FILE_NAME>

# 소유자와 그룹 동시에 변경
chown <OWNER>:<GROUP> <FILE_NAME>
```

### 2.2 파일 허가권 관리

```bash
# 파일 허가권 설정
# Symbolic Mode 또는 Octal Mode 사용 가능
chmod <PERMISSIONS> <FILE_NAME>

# 하위 디렉토리와 파일에 재귀적으로 허가권 설정
chmod -R <PERMISSIONS> <DIRECTORY_NAME>
```

#### 기호 (Symbolic) 모드

| 대상 | 기호 | 의미 |
|:---:|:---:|---|
| **User** | `u` | 소유자 |
| **Group** | `g` | 그룹 |
| **Others** | `o` | 그 외 사용자 |
| **All** | `a` | 모든 사용자 (u, g, o) |

| 연산자 | 의미 | 설명 |
|:---:|---|---|
| `+` | Add | 권한 추가 |
| `-` | Remove | 권한 제거 |
| `=` | Set | 권한 지정 (기존 권한 덮어쓰기) |

| 권한 | 기호 | 의미 |
|:---:|:---:|---|
| **Read** | `r` | 읽기 |
| **Write** | `w` | 쓰기 |
| **Execute** | `x` | 실행 |

#### 숫자 (Octal) 모드

| 권한 | 값 |
|:---:|:---:|
| **Read (r)** | 4 |
| **Write (w)** | 2 |
| **Execute (x)** | 1 |

## 3. 파일 검색 

```bash
find <DIRECTORY_NAME> <SEARCH_CRITERIA> <ACTION>
```

### 3.1 검색 기준 옵션

#### 파일 이름으로 검색

| 옵션 | 설명 |
|---|---|
| `-name` | 대소문자 구분하여 이름 검색 |
| `-iname` | 대소문자 구분하지 않고 이름 검색 |

#### 파일 크기로 검색

| 옵션 | 설명 |
|---|---|
| `-size +<SIZE>` | 지정 크기보다 큰 파일 |
| `-size -<SIZE>` | 지정 크기보다 작은 파일 |
| `-size <SIZE>` | 지정 크기와 정확히 일치하는 파일 |

* 단위

    * `k` (KB)
    
    * `M` (MB)
    
    * `G` (GB)

#### 파일 유형으로 검색

| 옵션 | 설명 |
|---|---|
| `-type f` | 일반 파일 |
| `-type d` | 디렉토리 |
| `-type l` | 심볼릭 링크 |

#### 소유자 및 권한으로 검색

| 옵션 | 설명 |
|---|---|
| `-user <OWNER>` | 소유자명으로 검색 |
| `-group <GROUP>` | 그룹명으로 검색 |
| `-perm <MODE>` | 권한으로 검색 |

#### 시간으로 검색

| 옵션 | 기준 | 설명 |
|---|---|---|
| `-mtime` | 수정 시간 | 파일 내용이 수정된 시간 |
| `-atime` | 접근 시간 | 파일에 접근한 시간 |
| `-ctime` | 변경 시간 | 메타데이터가 변경된 시간 |

* 시간 범위 지정

    * `+n`: n일 이전

    * `-n`: n일 이내

    * `n`: 정확히 n일 전

### 3.2 검색된 파일에 대한 동작

| 옵션 | 설명 |
|---|---|
| `-print` | 검색된 파일 경로 출력 (기본값) |
| `-ls` | `ls -l` 형식으로 상세 정보 출력 |
| `-delete` | 검색된 파일 삭제 |
| `-exec <CMD> {} \;` | 검색된 파일 (`{}`)에 대해 명령어 (`<CMD>`) 실행 |

## 4. 문자열 검색과 정규 표현식

```bash
grep [OPTIONS] PATTERN [FILE...]
```

### 4.1 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-i` | **Ignore case**: 대소문자 구분 없이 검색 |
| `-v` | **Invert match**: 패턴과 일치하지 않는 행만 출력 |
| `-r` | **Recursive**: 디렉토리 내 모든 하위 파일까지 검색 |
| `-n` | **Line number**: 일치하는 행의 번호도 함께 출력 |
| `-l` | **Files with matches**: 일치하는 내용이 있는 파일 이름만 출력 |
| `-c` | **Count**: 일치하는 행의 개수 출력 |
| `-E` | **Extended Regex**: 확장 정규 표현식 사용 (egrep과 동일) |

### 4.2 정규 표현식

| 메타 문자 | 의미 | 예시 | 해당 패턴과 일치하는 문자열 |
|:---:|---|---|---|
| `.` | 임의의 한 문자 | `a.c` | abc, aoc, a-c |
| `*` | 앞 문자가 0번 이상 반복 | `ab*c` | ac, abc, abbc |
| `+` | 앞 문자가 1번 이상 반복 (확장) | `ab+c` | abc, abbc |
| `?` | 앞 문자가 0번 또는 1번 등장 (확장) | `ab?c` | ac, abc |
| `^` | 행의 시작 | `^start` | |
| `$` | 행의 끝 | `end$` | |
| `[]` | 문자 집합 | `[a-z]` | 소문자 중 하나 |
| `[^]` | 문자 집합 부정 | `[^0-9]` | 숫자가 아닌 문자 |
| `\|` | OR 연산자 (확장) | `a\|b` | a 또는 b |
| `()` | 그룹화 | `(ab)+` | ab가 반복 |

## 5. awk 사용법

```bash
awk [OPTIONS] 'SCRIPT' <FILE_NAME>
```

### 5.1 주요 내장 변수

| 변수 | 설명 |
|:---:|---|
| `NR` | 현재 처리 중인 행 번호 |
| `NF` | 현재 행의 필드(열) 개수 |
| `$0` | 현재 행 (레코드) 전체 내용 |
| `$1`, `$2`... | 첫 번째, 두 번째 필드 내용 |
| `FS` | 입력 필드 구분자 (기본값: 공백) |
| `OFS` | 출력 필드 구분자 (기본값: 공백) |

### 5.2 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-F <DELIMITER>` | 필드 구분자를 지정 (예: `-F ','` csv 파일 처리 시) |
| `-v <VAR=VAL>` | awk 내부에서 사용할 변수 선언 |
| `-f <FILE>` | awk 스크립트가 저장된 파일 실행 |

### 5.3 awk 스크립트 예시

#### 조건에 맞는 행 출력

```bash
# 3번째 필드가 비어있는 행 출력
awk '$3 == ""' file.txt
```

#### 특정 필드만 출력

```bash
# 1번째 필드만 출력
awk '{print $1}' file.txt
```

#### 조건문 사용

```bash
# 1번 필드가 "User"이면 2번 필드 출력, 아니면 3번 필드 출력
awk '{if ($1 == "User") print $2; else print $3}' file.txt
```

#### 반복문 사용

```bash
# 각 행의 모든 필드를 순서대로 출력
awk '{for (i=1; i<=NF; i++) print $i}' file.txt
```

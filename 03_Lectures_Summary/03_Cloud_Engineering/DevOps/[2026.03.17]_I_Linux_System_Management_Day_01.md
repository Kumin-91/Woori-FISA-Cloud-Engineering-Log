## 1. Swap 메모리 비활성화

```bash
# 메모리 상태 및 Swap 사용량 확인
free -h

# 현재 활성화된 Swap 파티션 확인
cat /proc/swaps

# 모든 Swap 메모리 비활성화 (일시적)
sudo swapoff --all

# 비활성화 결과 확인
cat /proc/swaps

# 재부팅 후에도 비활성화 유지 (영구 설정)
# /etc/fstab 파일을 열어 swap 관련 라인을 주석 처리
sudo nano /etc/fstab

# [Example in /etc/fstab]
# /swap.img     none    swap    sw      0      0  <-- 이 라인을 주석(#) 처리
```
## 2. 시스템 Run Level

```bash
# 시스템 종료 (Poweroff)
sudo init 0
# 또는
sudo poweroff

# 시스템 재부팅 (Reboot)
sudo init 6
# 또는
sudo reboot
```

## 3. 서비스 관리

```bash
sudo systemctl <COMMAND> <SERVICE_NAME>
```

| 명령어 | 설명 |
|---|---|
| `status` | 서비스 상태 확인 |
| `start` | 서비스 시작 |
| `stop` | 서비스 중지 |
| `restart` | 서비스 재시작 |
| `reload` | 설정 파일만 다시 로드 |
| `enable` | 부팅 시 서비스 자동 시작 설정 |
| `disable` | 부팅 시 서비스 자동 시작 해제 |
| `is-active` | 서비스가 현재 실행 중인지 확인 (True/False) |
| `is-enabled` | 서비스가 자동 시작으로 설정되어 있는지 확인 |
| `list-units` | 현재 실행 중인 모든 서비스 목록 확인 (예: `sudo systemctl list-units --type=service --state=running`) |

## 5. 서비스 로그 확인

### 5.1 로그 파일 경로: `/var/log`

| 파일 경로 | 설명 |
|---|---|
| `/var/log/syslog` | 시스템의 전반적인 로그 |
| `/var/log/dmesg` | 부팅 시 커널이 출력하는 메시지 로그 |
| `/var/log/auth.log` | 사용자 로그인, sudo 사용 등 인증 관련 로그 |

### 5.2 로그 레벨

| Level | Keyword | 설명 |
|:---:|---|---|
| 0 | **Emergency** | 시스템이 사용할 수 없는 상태 |
| 1 | **Alert** | 즉각적인 조치가 필요한 상태 |
| 2 | **Critical** | 치명적인 상태 |
| 3 | **Error** | 오류 발생 |
| 4 | **Warning** | 경고 (주의 필요) |
| 5 | **Notice** | 정상적이지만 중요한 상황 |
| 6 | **Informational** | 일반적인 정보 메시지 |
| 7 | **Debug** | 디버깅용 메시지 |

### 5.3 로그 확인 명령어

```bash
# 특정 서비스의 로그 확인
sudo journalctl -u <SERVICE_NAME>

# 실시간 로그 모니터링 (Follow)
sudo journalctl -uf <SERVICE_NAME>

# 특정 레벨 이상의 로그만 확인 (예: error 이상)
sudo journalctl -p <LEVEL> -u <SERVICE_NAME>

# 시간 범위 지정하여 로그 확인
sudo journalctl --since "YYYY-MM-DD HH:MM:SS"
sudo journalctl --since "30 minutes ago"
sudo journalctl --since "today"

# 로그 출력을 파일로 저장 (tee 명령어 활용)
sudo journalctl | tee <LOG_FILE_PATH>
```

### 5.4 미션: 로그 분석 실습

1. 운영 서버에서 Warning 이상 로그만 확인하기

   ```bash
   sudo journalctl -p warning
   ```
    
2. 오늘 발생한 모든 로그 확인

   ```bash
   sudo journalctl --since "today"
   ```
    
3. [장애 대응] Docker 서비스 로그 확인

   ```bash
   sudo journalctl -u docker
   ```

4. [로그 검색] Nginx 로그 중 'database' 키워드 검색

   ```bash
   sudo journalctl -u nginx -g database
   ```
    
5. [복합 필터링] MySQL 서비스의 최근 30분간 Error 로그 검색

   ```bash
   sudo journalctl -u mysql --since "30 minutes ago" -p error
   ```

## 6. 사용자와 디렉토리 구조

* `#`: Root 사용자

* `$`: 일반 사용자

### 6.1 Root 권한 획득 및 사용자 전환

```bash
# Root 사용자로 전환 (환경 변수까지 root 설정으로 로드)
sudo -i
sudo su -

# Root 사용자로 전환 (현재 사용자의 환경 변수 유지)
sudo su
```

### 6.2 주요 시스템 디렉토리

| 디렉토리 | 설명 |
|:---:|---|
| `/` | 시스템의 최상위 디렉토리 |
| `/bin` | 기본 명령어 실행 파일 |
| `/usr` | 사용자 애플리케이션 및 파일 |
| `/etc` | 시스템 설정 파일들이 위치하는 곳 |
| `/var` | v로그, 스풀 등 수시로 변경되는 파일 |
| `/home` | 일반 사용자의 홈 디렉토리들이 위치 |
| `/root` | root 사용자의 홈 디렉토리 |
| `/opt` | 추가 애플리케이션 패키지 설치 경로 |

### 6.3 미션: 경로 확인

```bash
# JDK 실행 파일의 위치 확인
which java

# 심볼릭 링크의 원본 경로 확인
readlink -f $(which java)
```

## 7. 환경 변수

### 7.1 주요 환경 변수

| 변수명 | 설명 | 예시 |
|:---:|---|---|
| `$HOME` | 현재 사용자의 홈 디렉토리 | `/home/user` |
| `$PATH` | 실행 파일 탐색 경로 (콜론 `:`으로 구분) | `/bin:/usr/bin` |
| `$USER` | 현재 로그인한 사용자 ID | `neptune` |
| `$SHELL` | 사용 중인 Shell의 경로 | `/bin/zsh` |
| `$LANG` | 시스템 언어 설정 | `en_US.UTF-8` |

### 7.2 환경 변수 설정 파일 구조

#### 시스템 전역 설정

* `/etc/environment`: 기본 환경 변수

* `/etc/profile`: 로그인 쉘 초기화 스크립트

* `/etc/bash.bashrc`: Bash 쉘 전역 설정

#### 사용자별 설정

* `~/.profile`: 로그인 시 실행 (로그인 쉘)

* `~/.bashrc` (또는 `~/.zshrc`): 새로운 터미널 열 때마다 실행 (비로그인 쉘)

### 7.3 실습: JDK 설치 및 환경 변수 설정

1. 기존 JRE 삭제

   ```bash
   sudo apt remove openjdk-17-jre-headless
   ```

2. JDK 설치 (OpenJDK 17)

   ```bash
   sudo apt install openjdk-17-jdk
   ```

3. 환경 변수(`JAVA_HOME`) 설정

   ```bash
   # 쉘 설정 파일 열기 (zsh 사용 시 ~/.zshrc, bash 사용 시 ~/.bashrc)
   nano ~/.zshrc

   # 파일 끝에 다음 내용 추가:
   export JAVA_HOME="/usr/lib/jvm/java-17-openjdk-amd64"
   export PATH=$PATH:$JAVA_HOME/bin
   ```

4. 변경 사항 적용 및 확인

   ```bash
   # 설정 파일 다시 로드
   source ~/.zshrc

   # 확인
   echo $JAVA_HOME
   java -version
   ```
## 8. 패키지 개요 및 관리

### 8.1 패키지 관리 기본 명령어

```bash
# 최신 패키지 목록 업데이트
sudo apt update

# 설치된 패키지 업그레이드
sudo apt upgrade

# 패키지 설치
sudo apt install <PACKAGE_NAME>

# 설치된 패키지 목록 확인
sudo apt list --installed

# 패키지 검색
sudo apt search <PACKAGE_NAME>

# 패키지 상세 정보 확인
sudo apt show <PACKAGE_NAME>
```

### 8.2 패키지 삭제 및 정리

```bash
# 패키지 삭제 (설정 파일은 유지)
sudo apt remove <PACKAGE_NAME>

# 패키지 삭제 + 설정 파일까지 모두 삭제
sudo apt purge <PACKAGE_NAME>

# 의존성 패키지까지 포함하여 삭제
sudo apt autoremove --purge <PACKAGE_NAME>

# 불필요해진 의존성 패키지 및 캐시 정리
sudo apt autoremove
sudo apt clean
```

### 8.3 APT 주요 설정 파일

* `/etc/apt/sources.list`: 메인 패키지 저장소 목록

* `/etc/apt/sources.list.d/`: 추가된 서드파티 저장소 목록 (`.list` 또는 `.sources` 파일)

## 9. vi 편집기

### 9.1 vi 실행 및 모드

```bash
vi <FILE_NAME>
```

* Command Mode: 기본 모드, 커서 이동/복사/붙여넣기

* **Insert Mode: `i`, `a`, `o` 등을 눌러 텍스트 입력

* Ex Mode: `:`를 눌러 저장, 종료, 검색 등 명령 수행

### 9.2 주요 명령어

| 동작 | 명령어 (Command Mode) |
|:---:|---|
| **입력 모드 진입** | `i` (커서 앞), `a` (커서 뒤), `o` (다음 줄) |
| **저장하고 종료** | `:wq` 또는 `ZZ` |
| **강제 종료 (저장 X)** | `:q!` |
| **줄 삭제** | `dd` |
| **복사 / 붙여넣기** | `yy` (한 줄 복사) / `p` (붙여넣기) |
| **되돌리기(Undo)** | `u` |

### 9.3 문자열 검색 및 치환 (Ex Mode)

* 검색: `/keyword` (아래로 검색), `?keyword` (위로 검색)
  
    * `n`: 다음 찾기
    
    * `N`: 이전 찾기

* 치환

    ```vim
    # 현재 줄에서 첫 번째 old를 new로 변경
    :s/old/new

    # 파일 전체(%)에서 모든(g) old를 new로 변경
    :%s/old/new/g
    ```

## 10. Crontab

* [Crontab Generator](https://crontab-generator.org/)

### 10.1 Crontab 사용법

```bash
# 현재 사용자의 Crontab 설정 편집
crontab -e

# 설정된 Crontab 목록 확인
crontab -l

# 설정된 Crontab 모두 삭제
crontab -r

# 특정 사용자의 Crontab 편집
sudo crontab -u <USERNAME> -e
```

### 10.2 Crontab 시간 설정 구조

```
*     *     *     *     *      <COMMAND>
┬     ┬     ┬     ┬     ┬
│     │     │     │     │
│     │     │     │     └──── 요일 (0-6) (0: 일요일)
│     │     │     └────────── 월 (1-12)
│     │     └──────────────── 일 (1-31)
│     └────────────────────── 시 (0-23)
└──────────────────────────── 분 (0-59)
```

#### 특수 키워드

| 키워드 | 의미 |
|---|---|
| `@yearly` | 매년 1월 1일 실행 (`0 0 1 1 *`) |
| `@daily` | 매일 자정 실행 (`0 0 * * *`) |
| `@hourly` | 매시간 정각 실행 (`0 * * * *`) |
| `@reboot` | 시스템 부팅 시 실행 |

### 10.3 실습 예제

1. Simple Test: 1분마다 로그 남기기
   
   ```
   * * * * * echo "$(date): Cron Test" >> ~/cron_test.log
   ```

2. 현재 작업 디렉토리 경로 사용

   ```
   * * * * * echo "Test" >> $(pwd)/cron_log.txt
   ```

### 10.4 활용 미션

1. Docker 자원 정리 (매일 새벽 4시)

    ```
    0 4 * * * echo "$(date): Cleansing Docker $(docker system prune -af)" >> ~/docker_cleanup.log
    ```

2. 디스크 사용량 기록 (매일 새벽 4시)
    ```

    0 4 * * * echo "$(date): Disk Usage $(df -h /)" >> ~/disk_usage.log
    ```

3. Cron 자체 로그 백업 (최근 24시간 로그)

    ```
    0 4 * * * echo "$(date): Cron Logs" $(journalctl -u cron --since "24 hours ago") >> ~/cron_logs.log
    ```

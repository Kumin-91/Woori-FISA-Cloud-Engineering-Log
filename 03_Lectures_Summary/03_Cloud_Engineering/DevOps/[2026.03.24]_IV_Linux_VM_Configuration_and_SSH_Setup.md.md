## 1. server01 네트워크 설정

### 1.1 `/etc/netplan/01-netcfg.yaml` 파일 편집

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    ens33:
      dhcp4: no 
      addresses:
        - 10.0.2.15/24 
      routes:
        - to: default
          via: 10.0.2.2
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1
```

### 1.2 네트워크 설정 적용

```bash
# 권한 설정
sudo chmod 600 /etc/netplan/01-netcfg.yaml

# 네트워크 설정 적용
sudo netplan apply
```

### 1.3 네트워크 상태 확인

```bash
ip addr show ens33  # 인터페이스 이름 확인
```

```plain text
2: ens33: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP group default qlen 1000
    link/ether 00:0c:29:32:3e:58 brd ff:ff:ff:ff:ff:ff
    altname enp2s1
    inet 10.0.2.15/24 brd 10.0.2.255 scope global ens33
       valid_lft forever preferred_lft forever
    inet6 fe80::20c:29ff:fe32:3e58/64 scope link 
       valid_lft forever preferred_lft forever
```

### 1.4 호스트네임 설정 및 hosts 파일 편집

```bash
# hostname 설정
sudo hostnamectl set-hostname server01

# # hosts 파일 편집
sudo nano /etc/hosts
# 아래 내용을 추가
# 10.0.2.15 server01
# 10.0.2.20 server02
```

## 3. 비밀번호 없이 SSH 접속 설정

### 3.1 server01에서 SSH 키 생성 및 server02로 복사

```bash
# SSH 키 생성
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa -N ""

# SSH 공개키를 server02로 복사
ssh-copy-id -i ~/.ssh/id_rsa.pub fisa@server02
```

### 3.2 server02에서 SSH 키 생성 및 server01로 복사

```bash
# SSH 키 생성
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa -N ""

# SSH 공개키를 server01로 복사
ssh-copy-id -i ~/.ssh/id_rsa.pub fisa@server01
```

## 5. 미션

* 개인의 server02에 key를 짝꿍의 server01에 공유

    ```bash
    # server02 key를 짝꿍의 server01로 복사
    ssh-copy-id -i ~/.ssh/id_rsa.pub -p 2015 yongwan@172.21.24.71
    ```

* 서로 개인 파일 scp로 복사 붙여넣기

    ```bash
    scp -P 2015 ~/scptest.txt yongwan@172.21.24.71:~/
    ```

## 6. 미션: File 변경 감지

### 6.1 inotify-tools

* `inotifywait`: 이벤트 발생 시까지 대기하며, 이벤트 발생 시 해당 이벤트 정보를 출력하는 명령어

* `inotifywatch`: 지정된 파일이나 디렉토리에 대한 이벤트를 감시하여, 이벤트 발생 횟수와 시간을 기록하는 명령어

### 6.2 자동화 개요

* `inotifywait`를 사용하여 특정 파일의 변경을 감지

  * 변경된 파일은 외부에서 scp로 전송된 JAR 파일

* 변경이 감지되면, 기존 실행 중인 Java 프로세스 종료

* 새롭게 빌드된 JAR 파일을 백그라운드에서 실행

### 6. 자동화 스크립트 예시

```bash                                           
#!/bin/bash

FISA_FILE="./step06-buildGradleTest-0.0.1-SNAPSHOT.jar"
COOLDOWN=10
LAST_RUN=0

# inotifywait 실행
inotifywait -m -e close_write "$FISA_FILE" | while read -r directory events filename; do
    CURRENT_TIME=$(date +%s)
    
    if [ "$((CURRENT_TIME - LAST_RUN))" -gt "$COOLDOWN" ]; then
        echo "$(date): $filename 파일이 수정되었습니다."
        LAST_RUN=$CURRENT_TIME

        # 기존 자바 프로세스 종료
        killall -9 java 2>/dev/null

        # 기존 자바 프로세스 종료 대기
        sleep $COOLDOWN

        # 새 프로세스 백그라운드 실행
        java -jar "$FISA_FILE" &
    else
        echo "$(date): 쿨다운 기간 중입니다. 실행하지 않음."
    fi
done
```

## 1. Docker Compose 기본 명령어

```bash
# 컨테이너 시작
docker-compose up

# 백그라운드에서 컨테이너 시작
docker-compose up -d

# 컨테이너 로그 보기
docker-compose logs

# 컨테이너 중지
docker-compose stop

# 컨테이너 시작
docker-compose start

# 컨테이너 재시작
docker-compose restart

# 컨테이너 중지 및 제거
docker-compose down
```

## 2. Kubernetes

### 2.1 Minikube 설치

```bash
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube && rm minikube-linux-amd64

# Minikube 버전 확인
minikube version
```

### 2.2 Kubectl 설치

```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl

# Kubectl 버전 확인
kubectl version
```

### 2.2 Minikube 기본 명령어

```bash
# Minikube 클러스터 시작
minikube start

# Minikube 클러스터 상태 확인
minikube status

# Minikube 클러스터 목록 확인
minikube profile list

# Minikube 클러스터 중지
minikube stop
```

### 2.3 Kubectl 기본 명령어

```bash
# 클러스터의 모든 리소스 확인
kubectl get all

# 모든 네임스페이스의 모든 포드 확인
kubectl get po -A

# 서비스 확인
kubectl get services

# 파드 확인
kubectl get pods

# 디플로이먼트 확인
kubectl get deployments

# Pod 내부 접속
kubectl exec -it <pod-name> -- /bin/bash

# Pod 삭제
kubectl delete pod <pod-name>

# Proxy 설정
kubectl proxy --address='0.0.0.0' &
```

## 3. 간단한 Kubernetes 애플리케이션 배포

```bash
# 간단한 애플리케이션 배포
kubectl create deployment hello-minikube --image=kicbase/echo-server:1.0

# 간단한 애플리케이션 서비스 노출
kubectl expose deployment hello-minikube --type=NodePort --port=8080

# 서비스 URL 확인
minikube service hello-minikube --url

# 서비스 확인
kubectl get services hello-minikube

# 포트포워딩
kubectl port-forward service/hello-minikube 7080:8080
```

```bash
kubectl create deployment nginx --image=nginx
kubectl expose deployment nginx --type=NodePort --port=80
minikube port-forward service/nginx 80:80
```

## 4. Minikube 대시보드

```bash
# 설치된 에드온 확인
minikube addons list

# 대시보드 에드온 활성화
minikube dashboard

# 매트릭스 서버 에드온 활성화
minikube addons enable metrics-server
```

## 5. 미션: Pod 개수 확인 및 스케일링

```bash
# 현재 Pod 개수 확인
kubectl get pods

# 디플로이먼트 스케일링 (예: 3개로 스케일링)
kubectl scale deployment hello-minikube --replicas=3

# 스케일링 후 Pod 개수 확인
kubectl get pods

# 디플로이먼트 스케일링 (예: 1개로 스케일링)
kubectl scale deployment hello-minikube --replicas=1

# 스케일링 후 Pod 개수 확인
kubectl get pods
```

## 6. 미션: Gradle 프로젝트 GitHub에 Push & Jenkins에서 Webhook으로 빌드 실행

### 6.1 step06 단계 프로젝트를 GitHub에 Push (`git bash` 이용)

```bash
# 기존 레포지토리 가져오기
git clone https://github.com/Kumin-91/fisaDevOps01.git

# 레포지토리로 이동
cd fisaDevOps01

# step06 단계 프로젝트 파일 복사
cp -r /c/ce06/SpringBoot/step06_buildGradleTest/* .

# 변경 사항 스테이징
git add .

# 커밋
git commit -m "Add step06 project files"
```

### 6.2 Jenkins에서 GitHub Webhook 설정하여 Push 시 Pipiline 실행되도록 설정

#### 1. Pipeline 코드 작성

```groovy
pipeline {
    agent any
	
    environment {
        GITHUB_REPO = 'https://github.com/Kumin-91/fisaDevOps01.git'
        BRANCH_NAME = 'main'
    }

    stages {
        stage('Checkout') {
            steps {
                git branch: "${BRANCH_NAME}", url: "${GITHUB_REPO}"
                
                echo '**********'
                sh 'ls -al'  
                echo '**********'
            }
        }
		//gradle 인 경우의 build명령어 / maven인 경우의 build 명령어
        stage('Build') {
            steps {
                script {
                    if (fileExists('gradlew')) {
                        dir('./') {
                            sh 'chmod +x gradlew'
                            sh './gradlew build'
                        }
                    } else if (fileExists('pom.xml')) {
                        dir('./') {
                            sh 'mvn clean package'   
                        }
                    } else {
                        error 'Gradle 또는 Maven 프로젝트가 아님'
                    }
                }
            }
        }
    }

    post {
        success {
            echo '✅ 빌드 성공!'
        }
        failure {
            echo '❌ 빌드 실패! 오류 확인 필요!'
        }
    }
}
```

## 7. 미션: CI/CD 기초 bind mount & build

### 7.1 Host에 마운트 폴더 생성

```bash
mkdir -p ~/appjardir
```

### 7.2 bind 옵션을 적용하면서 Jenkins container 생성 및 자동 생성된 bind 폴더 확인

```bash
docker run --name myjenkins2 -p 8090:8080 -v ~/appjardir:/var/jenkins_home/appjar jenkins/jenkins:lts-jdk17
```

### 7.3 root 권한으로 폴더에 쓰기 권한 부여 (필수)

```bash
sudo chown -R ${USER}:${USER} ~/appjardir
sudo chmod -R 770 ~/appjardir
```

### 7.4 Pipeline에 jar 파일을 bind mount된 폴더로 이동하는 스테이지 추가

```groovy
// 기존 Pipeline 코드에서 Build 스테이지 이후에 다음 스테이지 추가
        stage('Move Jar') {
            steps {
                script {
                    dir('./') {
                        sh 'cp ./build/libs/*.jar ${JENKINS_HOME}/appjar/'
                    }
                }
            }
        }
```

### 7.5 github에 수정 후 sh 프로그램 재실행하면서 정상 실행 여부 확인

#### 1. ngrok 실행

```powershell
./ngrok http 8090
```

#### 2. GitHub

이전 미션에서 사용한 Repository를 이용하여 미션 진행 → GitHub에서 추가적인 Webhook 설정은 필요 없음

새로운 Jenkins에서 `Move Jar` 스테이지가 추가된 Pipeline 코드로 수정 후 Push

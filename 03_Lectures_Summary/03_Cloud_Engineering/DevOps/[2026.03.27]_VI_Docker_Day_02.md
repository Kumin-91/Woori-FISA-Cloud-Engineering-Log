## 1. 미션: Docker로 MySQL 컨테이너 실행

```bash
docker run -d \
    --name mysql \
    -e MYSQL_ROOT_PASSWORD=root \
    -e MYSQL_DATABASE=fisa \
    -e MYSQL_USER=user01 \
    -e MYSQL_PASSWORD=user01 \
    -p 3306:3306 \
    mysql:8
```

## 2. Docker Network

```bash
# Docker Network 생성
docker network create my-network

# Docker Network 확인
docker network ls

# Docker Network 상세 정보 확인
docker inspect my-network

# 컨테이너를 Docker Network에 연결하여 실행
docker run --name ns1 -p 80:80 --network my-network nginx:latest  
```

## 3. 미션: Docker로 Spring Boot 애플리케이션 컨테이너 실행

### 3.1 Dockerfile 생성

```Dockerfile
# 베이스 이미지 설정
FROM eclipse-temurin:17-jdk

# 작업 디렉토리 설정
WORKDIR /app

# 애플리케이션 JAR 파일 복사
COPY ./step04-empAppMaven-0.0.1-SNAPSHOT.jar /app/step04-empAppMaven.jar

# 포트 노출
EXPOSE 8082

# 애플리케이션 실행 명령어
ENTRYPOINT ["java", "-jar", "/app/step04-empAppMaven.jar"]
```

### 3.2 Docker Image 빌드

```bash
docker build -t miu91/emp-app:latest .
```

### 3.3 Docker Image 업로드

```bash
docker push miu91/emp-app:latest
```

### 3.4 Docker Image 다운로드 및 실행

```bash
docker pull miu91/emp-app:latest
docker run -d --name emp-app -p 8082:8082 --network my-network miu91/emp-app:latest
```

## 2. Helm

쿠버네티스 패키지 매나저로 쿠버네티스 애플리케이션을 패키징, 배포 및 관리하는 도구입니다. Helm을 사용하면 복잡한 애플리케이션을 쉽게 설치하고 관리할 수 있습니다.

### 2.1 Helm 설치

```bash
# Helm 설치 스크립트 실행
curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

# 설치된 Helm 버전 확인
helm version

# /usr/local/bin/ 디렉토리에서 Helm 실행 파일 확인
ls /usr/local/bin/

# Bitnami Helm Repository 추가
helm repo add bitnami https://charts.bitnami.com/bitnami

# Helm 로컬 Repository 리스트
helm repo list

# Helm Repository 업데이트
helm repo update

# Nginx Helms Chart 검색
helm search repo nginx
```

### 2.2 Helm을 사용하여 Nginx 설치

```bash
# mychart라는 이름으로 Bitnami Nginx Helm Chart 설치
helm install mychart bitnami/nginx

# 설치된 Helm 릴리스 확인
helm list
helm ls

# mychart 부가 정보 확인
helm get manifest mychart

# mychart 삭제
helm uninstall mychart
```

### 2.3 실전 예제

```bash
# mychartfisa라는 이름으로 Helm Chart 생성
helm create mychartfisa

# Helm Chart 설치
helm install my-nginx-fisa ./mychartfisa

# Kubernetes 리소스 확인
kubectl get all

# Helm Chart 삭제
helm uninstall my-nginx-fisa

# Helm Chart 재설치
helm install my-nginx-fisa ./mychartfisa

# values.yaml 파일 수정
nano mychartfisa/values.yaml

# 수정된 values.yaml 적용하여 Helm Chart 업데이트
helm upgrade my-nginx-fisa ./mychartfisa

# Helm Chart 삭제
helm uninstall my-nginx-fisa

# Helm Chart 디렉토리 삭제
rm -rf mychartfisa
```

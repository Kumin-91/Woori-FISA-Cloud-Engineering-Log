## 1. Kubernetes 삭제 관련 명령어

```bash
# Deployment 삭제
kubectl delete deployment <deployment-name>

# Service 삭제
kubectl delete service <service-name>

# Pod 삭제
kubectl delete pod <pod-name>
```

## 2. Kubernetes 실습 (명령형)

```bash
# 현재 클러스터 상태 확인
kubectl get all

# Nginx Deployment 생성 (Pod 1개)
kubectl create deployment nginx --image=nginx

# Nginx Deployment 삭제
kubectl delete deployment nginx

# Nginx Deployment 생성 (Pod 3개)
kubectl create deployment nginx --image=nginx --replicas=3

# Deployment 상태 확인
kubectl get deployments

# Nginx Pod 로그 확인
kubectl logs -l app=nginx

# Nginx Service 생성
kubectl expose deployment nginx --port=80 --type=NodePort

# Service 확인
kubectl get services

# Nginx Service 상세 정보 확인
kubectl describe service nginx

# Port forwarding 설정 (모든 인터페이스에서 접근 가능하도록)
kubectl port-forward service/nginx 8080:80 --address 0.0.0.0

# Pod 상세 정보 확인
kubectl get pods -o wide

# Nginx Pod 삭제
kubectl delete pod nginx-<random-suffix>

# Nginx Deployment 스케일링 (Pod 5개)
kubectl scale deployment nginx --replicas=5

# Nginx Service 삭제
kubectl delete service nginx

# Nginx Deployment 삭제
kubectl delete deployment nginx
```

## 3. Kubernetes 실습 (선언형)

```bash
# YAML 파일을 사용하여 Nginx Deployment 생성
kubectl apply -f nginx-deployment.yaml

# YAML 파일을 사용하여 Nginx Service 생성
kubectl apply -f nginx-service.yaml

# YAML 파일 수정 후 적용 (Pod 수 변경 3 -> 5)
kubectl apply -f nginx-deployment.yaml

# YAML 파일을 사용하여 Nginx Deployment 삭제
kubectl delete -f nginx-deployment.yaml

# YAML 파일을 사용하여 Nginx Service 삭제
kubectl delete -f nginx-service.yaml
```

## 4. Namespace

```bash
# Namespace 확인
kubectl get namespaces

# Namespace 생성
kubectl create namespace fisans

# Namespace 상세 정보 확인
kubectl describe namespace fisans

# Deployment를 특정 Namespace에 생성
kubectl create deployment nginx --image=nginx -n fisans

# Namespace 내 Deployment 확인
kubectl get deployments -n fisans

# Namespace 내 모든 리소스 확인
kubectl get all -n fisans

# Namespace 내 Deployment 삭제
kubectl delete deployment nginx -n fisans

# Namespace 삭제
kubectl delete namespace fisans
```

## 6. Kubernetes와 Container 관계

* Kubernetes: 관리자

    * Kubernetes는 Conatiner를 직접 실행하지 않고, Container runtime을 통해 실행을 위임

* Container runtume: 실행 엔진

* 실행 구조: `kubectl` -> `kubelet` -> `Container runtime` (예: Containerd) -> `Container` (예: Nginx)

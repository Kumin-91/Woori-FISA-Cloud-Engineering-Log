# Kubernetes Day 05

## 1. Helm 복습

### 1.1 Template 생성 후 설치 및 편집

```bash
# Chart Template 생성
helm create mychartfisa

# Template으로 부터 Chart 설치
helm install my-nginx-fisa ./mychartfisa

# Chart 내용 편집
nano mychartfisa/values.yaml

# 변경 사항 적용
helm upgrade my-nginx-fisa ./mychartfisa
```

### 1.2 Template 생성하지 않고 설치 및 편집

```bash
# Chart 설치
helm install my-nginx-fisa bitnami/nginx

# Chart 내용 편집
helm edit my-nginx-fisa

# 변경 사항 적용
helm upgrade my-nginx-fisa bitnami/nginx
```

### 1.3 이미 존재하는 value.yaml 파일을 사용하여 설치, 편집, 삭제 과정

```bash
# Chart 설치
helm install my-nginx-fisa -f values.yaml bitnami/nginx

# Chart 내용 편집
nano values.yaml

# 변경 사항 적용
helm upgrade my-nginx-fisa -f values.yaml bitnami/nginx
```

## 2. Prometheus & Grafana

### 2.1 Prometheus

데이터를 수집하는 시스템으로, 시계열 데이터베이스입니다. Kubernetes 클러스터에서 애플리케이션과 인프라의 성능을 모니터링하는 데 사용됩니다.

### 2.2 Grafana

데이터 시각화 도구로, Prometheus와 같은 데이터 소스에서 데이터를 가져와 대시보드 형태로 시각화합니다. 이를 통해 시스템의 상태를 쉽게 파악할 수 있습니다.

### 2.3 Helm을 통한 Prometheus와 Grafana 설치

```bash
# Helm 저장소 추가
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts

# Helm 저장소 목록 확인
helm repo list

# Helm 저장소 업데이트
helm repo update

# Namespace 생성
kubectl create namespace monitoring

# Namespace 확인
kubectl get namespaces

# values.yaml 파일 생성
nano values.yaml

# YAML 파일을 사용하여 Prometheus 설치
helm install prometheus prometheus-community/kube-prometheus-stack \
    -f values.yaml \
    -n monitoring

# YAML 수정 후 업그레이드
helm upgrade prometheus prometheus-community/kube-prometheus-stack \
    -f values.yaml \
    -n monitoring

# 설치된 Helm 릴리스 확인
helm list -n monitoring

# 설치된 리소스 확인
kubectl get all -n monitoring

# Port forwarding 설정
kubectl port-forward -n monitoring svc/prometheus-kube-prometheus-prometheus 9090 --address 0.0.0.0
kubectl port-forward -n monitoring svc/prometheus-grafana 3000:80 --address 0.0.0.0
```

```yaml

  enabled: true

    port: 9100
    targetPort: 9100

prometheus:
  prometheusSpec:
    nodeExporter:
      enabled: true

```

## 4. VM에 MySQL, Exporter, Prometheus 및 Grafana 설치

Kubernetes가 아닌 VM 환경에서 MySQL과 MySQL Exporter를 설치하여 Prometheus와 Grafana로 모니터링하는 과정을 진행합니다.

바이너리 설치 방법은 공식 문서를 참고하여 진행합니다.

### 4.1 MySQL 설치

```bash
sudo apt update
sudo apt install mysql-server -y
sudo systemctl start mysql
sudo systemctl enable mysql
```

### 4.2 Prometheus 설치

```bash
# 전용 사용자 계정 생성
sudo useradd --no-create-home --shell /bin/false prometheus

# Prometheus 디렉토리 생성
sudo mkdir -p /etc/prometheus
sudo mkdir -p /var/lib/prometheus

# Prometheus 디렉터리 권한 설정
sudo chown prometheus:prometheus /etc/prometheus
sudo chown prometheus:prometheus /var/lib/prometheus

# Prometheus 바이너리 다운로드
curl -LO https://github.com/prometheus/prometheus/releases/download/v3.11.0/prometheus-3.11.0.linux-amd64.tar.gz

# 압축 해제
tar -xvf prometheus-3.11.0.linux-amd64.tar.gz

# Prometheus 바이너리 이동
sudo mv prometheus-3.11.0.linux-amd64/prometheus /usr/local/bin/
sudo mv prometheus-3.11.0.linux-amd64/promtool /usr/local/bin/
sudo mv prometheus-3.11.0.linux-amd64/prometheus.yml /etc/prometheus/prometheus.yml

# prometheus.yml 파일 편집
sudo nano /etc/prometheus/prometheus.yml

# Prometheus 서비스 파일 생성
sudo tee /etc/systemd/system/prometheus.service <<EOF
[Unit]
Description=Prometheus
Wants=network-online.target   
After=network-online.target

[Service]
User=prometheus
Group=prometheus
Type=simple
ExecStart=/usr/local/bin/prometheus \\
  --config.file=/etc/prometheus/prometheus.yml \\
  --storage.tsdb.path=/var/lib/prometheus \\
  --web.listen-address=0.0.0.0:9090

[Install]
WantedBy=multi-user.target
EOF

# Prometheus 서비스 시작 및 활성화
sudo systemctl daemon-reload
sudo systemctl start prometheus
sudo systemctl enable --now prometheus

# Prometheus 상태 확인
sudo systemctl status prometheus
```

### 4.3 Grafana 설치

```bash
# 저장소 업데이트
sudo apt update

# 필수 패키지 설치
sudo apt install -y apt-transport-https software-properties-common wget

# Grafana GPG 키 추가
wget -q -O - https://packages.grafana.com/gpg.key | sudo apt-key add -
echo "deb https://packages.grafana.com/oss/deb stable main" | sudo tee -a /etc/apt/sources.list.d/grafana.list

# Grafana 설치
sudo apt update && sudo apt install -y grafana

# Grafana 서비스 시작 및 활성화
sudo systemctl start grafana-server
sudo systemctl enable grafana-server

# Grafana 상태 확인
sudo systemctl status grafana-server
```

### 4.4 Exporter 설치

#### 1. Node Exporter 설치

```bash
# Node Exporter 다운로드
curl -LO https://github.com/prometheus/node_exporter/releases/download/v1.10.2/node_exporter-1.10.2.linux-amd64.tar.gz

# 압축 해제
tar -xvf node_exporter-1.10.2.linux-amd64.tar.gz

# Node Exporter 이동
sudo mv node_exporter-1.10.2.linux-amd64/node_exporter /usr/local/bin/

# Node Exporter 서비스 파일 생성
sudo tee /etc/systemd/system/node_exporter.service <<EOF
[Unit]
Description=Node Exporter
Wants=network-online.target
After=network-online.target

[Service]
User=prometheus
Group=prometheus
Type=simple
ExecStart=/usr/local/bin/node_exporter --web.listen-address=":9101"

[Install]
WantedBy=multi-user.target
EOF

# Node Exporter 서비스 시작 및 활성화
sudo systemctl daemon-reload
sudo systemctl start node_exporter
sudo systemctl enable --now node_exporter

# Node Exporter 상태 확인
sudo systemctl status node_exporter

# Prometheus 설정 파일에 Node Exporter 추가
sudo nano /etc/prometheus/prometheus.yml
```

```yaml
scrape_configs:
  - job_name: 'node'
    static_configs:
      - targets: ['localhost:9101']
```

#### 2. MySQL Exporter 설치

```bash
# MySQL Exporter 설치
curl -LO https://github.com/prometheus/mysqld_exporter/releases/download/v0.19.0/mysqld_exporter-0.19.0.linux-amd64.tar.gz

# 압축 해제
tar -xvf mysqld_exporter-0.19.0.linux-amd64.tar.gz

# MySQL Exporter 이동
sudo mv mysqld_exporter-0.19.0.linux-amd64/mysqld_exporter /usr/local/bin/

# MySQL Exporter 서비스 파일 생성
sudo tee /etc/systemd/system/mysqld_exporter.service <<EOF
[Unit]
Description=Prometheus MySQL Exporter
After=network.target

[Service]
User=prometheus
Group=prometheus
Type=simple
ExecStart=/usr/local/bin/mysqld_exporter --config.my-cnf=/etc/.my.cnf --web.listen-address=":9104"
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# MySQL Exporter 설정
sudo nano /etc/.my.cnf
# 다음과 같이 MySQL 사용자와 비밀번호를 설정
# [client]
# user=prometheus
# password=prometheus

# 파일 권한 설정
sudo chown prometheus:prometheus /etc/.my.cnf
sudo chmod 600 /etc/.my.cnf

```

```sql
CREATE USER 'prometheus'@'%' IDENTIFIED BY 'prometheus';
```

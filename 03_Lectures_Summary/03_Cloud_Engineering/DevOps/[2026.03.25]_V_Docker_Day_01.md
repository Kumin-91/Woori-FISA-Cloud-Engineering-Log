## 1. Docker Garbage Collection

```bash
# 중지된 모든 컨테이너 삭제
docker container prune

# 사용하지 않는 이미지 삭제 (dangling images)
docker image prune

# 컨테이너와 연결되지 않은 모든 볼륨 삭제
docker volume prune

# 컨테이너와 연결되지 않은 모든 네트워크 삭제
docker network prune

# 사용하지 않는 모든 오브젝트를 삭제
docker system prune -a
```

## 2. Docker Images

```bash
# 도커 이미지 목록 확인
docker images

# 도커 이미지 다운로드
docker pull <IMAGE_NAME>:<TAG>

# 도커 이미지 삭제
docker rmi <IMAGE_ID>

# 모든 도커 이미지 삭제
docker rmi $(docker images -q) 
```

## 3. Clean Installation of Docker

### 3.1 기존 Docker 환경 정리

```bash
# Docker Container 종료 및 삭제
docker stop $(docker ps -aq)
docker rm $(docker ps -aq)

# Docker Prune으로 모든 리소스 정리
docker system prune -a --volumes -f

# Docker 삭제
sudo apt-get purge -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo apt-get purge -y docker.io docker-doc docker-compose docker-compose-v2 podman-docker containerd runc
sudo apt-get autoremove -y

# Docker 관련 디렉토리 삭제
sudo rm -rf /var/lib/docker
sudo rm -rf /var/lib/containerd

# Docker 설정 삭제
sudo rm -rf /etc/docker
sudo rm -f /etc/apt/keyrings/docker.gpg
sudo rm -rf /etc/apt/sources.list.d/docker.list
```

### 3.2 Docker 설치

```bash
# Docker 설치
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg lsb-release

# Docker 공식 GPG 키 추가
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# Docker 저장소 추가
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Docker 설치
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

### 3.3 Docker Daemon 실행

```bash
# Docker 그룹에 현재 사용자 추가
sudo usermod -aG docker $USER
newgrp docker

# Docker Daemon 실행
sudo systemctl start docker
sudo systemctl enable docker
```

## 4. Docker 실습

### 4.1 Tomcat 10

```bash
# Tomcat 10 컨테이너 생성 및 실행
docker run --name myserver01 -p 8080:8080 tomcat:10

# Tomcat 10 컨테이너 로그 확인
docker logs myserver01

# Tomcat 10 컨테이너 상세 정보 확인
docker inspect myserver01

# Tomcat 10 컨테이너 접속
docker exec -it myserver01 bash
```

### 4.2 Nginx

```bash
# nginx 컨테이너 생성 및 실행
docker run --name myserver02 -p 80:80 nginx

# 컨테이너 내부 파일 목록 확인
docker exec -it myserver02 bash -c 'ls -l'

# 한글 깨짐 방지 위해 UTF-8 설정
docker exec -it -e  LC_ALL=C.UTF-8 myserver02 bash
```

### 4.3 Docker UI ManagerTool

```bash
docker run -d -p 9000:9000 --privileged -v /var/run/docker.sock:/var/run/docker.sock uifd/ui-for-docker
```

## 5. Dockerfile

```Dockerfile
# 기반 이미지 설정
FROM

# 이미지 빌드 시점에 실행할 명령어 설정
RUN

# 애플리케이션 파일 복사
COPY
ADD

# 작업 디렉토리 설정
WORKDIR

# 컨테이너 포트 노출
EXPOSE

# 컨테이너 실행 시 실행할 명령어 설정
CMD
ENTRYPOINT
```

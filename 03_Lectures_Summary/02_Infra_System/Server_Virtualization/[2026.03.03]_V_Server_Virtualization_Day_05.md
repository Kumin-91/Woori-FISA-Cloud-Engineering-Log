## 2. Fibre Channel Storage

### 2.0 Terminology

* **DAS (Direct Attached Storage):** IDE, SATA, SCSI 등으로 서버에 직접 연결된 스토리지

* **SAN (Storage Area Network)**

    * FC, iSCSI, FCoE 등 네트워크를 통해 서버와 스토리지를 연결하는 방식

    * WWN (World Wide Name): FC 스토리지의 고유 식별자

* **NAS (Network Attached Storage)**

    * NFS, SMB/CIFS 등 네트워크 파일 공유 프로토콜을 사용하는 스토리지

    * IP 주소로 접근하며, 파일 단위로 데이터 전송

* **HBA (Host Bus Adapter):** 서버와 스토리지 간의 통신을 담당하는 인터페이스 카드

* **SCSI (Small Computer System Interface):** 서버와 스토리지 간의 데이터 전송을 위한 표준 인터페이스

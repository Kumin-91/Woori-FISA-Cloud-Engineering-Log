## 1. Storage Concepts

* ESXi는 블록 스토리지에서는 주로 VMFS Datastore를 사용하고, 환경에 따라 NFS/vVol Datastore도 함께 사용 가능

* **RDM (Raw Device Mapping):** VM이 특정 LUN에 직접 접근하도록 매핑하는 방식

## 2. Storage Types and Terminologies

* **DAS (Direct Attached Storage):** IDE, SATA, SCSI 등으로 서버에 직접 연결된 스토리지

* **SAN (Storage Area Network):** FC, iSCSI, FCoE 등 네트워크를 통해 서버와 스토리지를 연결하는 방식

* **WWN (World Wide Name):** FC 스토리지의 고유 식별자

* **NAS (Network Attached Storage):**  NFS, SMB/CIFS 등 네트워크 파일 공유 프로토콜을 사용하는 스토리지

* **HBA (Host Bus Adapter):** 서버와 스토리지 간의 통신을 담당하는 인터페이스 카드

* **SCSI (Small Computer System Interface):** 서버와 스토리지 간의 데이터 전송을 위한 표준 인터페이스

* **LUN (Logical Unit Number):** 스토리지에서 논리적으로 구분된 저장 공간 단위

* **RAID (Redundant Array of Independent Disks):** 여러 디스크를 하나의 논리 볼륨처럼 구성해 성능/가용성을 높이는 방식

* **Hard Zoning:** 스위치 포트 (물리 연결) 기반으로 통신 대상을 제한하는 방식

* **Soft Zoning:** WWN 기반으로 통신 대상을 제한하는 논리적 분리 방식

## 5. iSCSI Storage

### 5.1 iSCSI Addressing

* **iSCSI Qualified Name (IQN):** iSCSI 장치의 고유 식별자 형식

    * 형식 예시: `iqn.yyyy-mm.<reversed-domain>:<unique-name>`

    * 예시: `iqn.2026-03.com.example:storage.target01`

* **EUI (Extended Unique Identifier):** IEEE 표준을 따르는 또 다른 iSCSI 식별자 형식 (예: `eui.02004567A425678D`)

* **Initiator:** 스토리지 자원을 요청하고 사용하는 클라이언트

* **Target:** 스토리지 자원을 제공하는 스토리지 서버/어레이

## 6. VMFS Datastores

* VMFS Datastore는 일반적으로 최대 64TB까지만 구성 가능

* VMFS6 기준 단일 Extent를 권장하며, Extent 추가는 운영 복잡도를 높일 수 있어 신중히 사용

## 7. vSAN Datastores

* **SDS (Software-Defined Storage):** 서버 로컬 디스크를 클러스터 단위 스토리지로 추상화하여 Datastore로 제공

* 정책 기반 저장소 관리와 함께 VM 단위로 가용성/성능 정책 적용 가능

## 8. About Templates

* VM의 구성, OS, 애플리케이션 등을 포함하는 VM의 사본으로, 새로운 VM을 빠르게 배포할 수 있도록 하는 기능

* Template은 변경이 불가능

* 일반적으로 Template 변환 전 VM 전원을 종료한 상태에서 작업

### 8.1 Clone a VM

* **Clone to VM**

    * 기존 VM은 유지되고, 새로운 VM을 생성
    
    * VM을 복제하여 새로운 VM 생성

* **Clone to Template**

    * 기존 VM은 유지되고, Template으로 복제
    
    * VM을 복제하고 복제된 VM을 Template으로 변환

### 8.2 Convert a VM to Template

* **Convert to Template**

    * 기존 VM은 삭제되고 Template으로 변환

    * .vmx 파일을 .vmtx 파일로 변환하여 Template으로 사용

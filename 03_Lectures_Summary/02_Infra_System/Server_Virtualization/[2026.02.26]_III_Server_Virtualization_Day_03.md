## 2. Communication between ESXi and vCenter Server

* **Flow:** vSphere Client → vpxd (vCenter) → vpxa (ESXi Agent) → hostd (ESXi Daemon) → VM

* **hostd**

    * ESXi 호스트에서 실행되는 데몬
    
    * 사용자와 웹으로 ESXi 호스트와 통신하는 역할 (VM 관리, 리소스 모니터링 등)

    * 사용자 → VMware Host Client

* **vpxa (Virtual Provisioning X Agent)**

    * ESXi 호스트에서 실행되는 에이전트

    * vCenter와 ESXi 호스트 간의 통신을 담당하는 에이전트

* **vpxd (Virtual Provisioning X Daemon)**

    * vCenter에서 실행되는 데몬
    
    * vCenter의 주요 기능을 담당 (호스트 관리, VM 관리, 리소스 할당 등)

    * 사용자 → vSphere Client

* **Orphaned VM:** ESXi에 직접 접속해서 VM을 삭제한 경우, vCenter Database에는 존재하지만 실제로는 존재하지 않는 VM

## 6. Roles and Permissions

* **Object:** 행동의 대상 (예: VM, Host, Cluster 등)

* **Role:** 역할, Privilege의 집합 (예: Admin, Read-only 등)

* **Privilege:** 권한 (예: VM Power On, VM Power Off, VM Monitor 등)

* **Permission:** 허가

* **Scenario**

    * User Privilege이 Group Privilege보다 우선

    * Group Role의 경우, 하위 객체가 상위 객체보다 우선 (VM 권한이 Datacenter 권한보다 우선)

    * Specific 할 수록 우선

## 8. Virtual Networks

### 8.1 Terminology

* **VM Port Group**

    * 가상 스위치에서 VM이 연결되는 포트 그룹

    * Uplink: to the PNIC (Physical Network Interface Card)

        * VMNIC0, VMNIC1, VMNIC2, ...

* **Uplink Port Group**

* 가상 스위치에서 PNIC이 연결되는 포트 그룹

* **vSwitch**

    * Layer 2

* **Kernel Port**

    * IP 주소 할당 가능

    * 특정 Port Group에 연결

    * ESXi를 설치 할 때 IP가 할당된 포트 (VMKernel 0)

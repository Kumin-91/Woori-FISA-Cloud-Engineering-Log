## 1. TCP: Transmission Control Protocol

* **Connection-Oriented Protocol**

    * 신뢰성 있는 데이터 전송 보장

    * 상대방이 패킷을 잘 받았는지, 순서대로 도착했는지 확인

* **Three-Way Handshake**

    * SYN: 연결 요청

    * ACK: 응답 확인

    * ACK: 연결 성립 확인

* **Four-Way Handshake**

    * FIN: 연결 종료 요청

    * ACK: 종료 요청 확인

    * FIN: 종료 요청

    * ACK: 종료 확인

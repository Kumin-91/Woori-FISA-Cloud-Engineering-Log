## 1. Node vs Host

| **구분** | **Node** | **Host** |
| --- | --- | --- |
| 정의 | 네트워크 연결 지점 그 자체 | 네트워크에 주소 (IP 등)를 갖고 연결된 종단 장치 |
| 핵심 역할 | 데이터의 전달, 중계, 생성, 수신 | 애플리케이션 실행, 서비스 제공 및 이용 |
| 포함 범위 | 가장 넓음 (허브, 스위치, 라우터, PC 등) | 상대적 좁음 (PC, 서버, 스마트폰 등) |
| 식별자 | MAC 주소만 있어도 노드라 불림 | 통신을 위한 고유 주소 (IP)가 필수적 |

* **Node:**

    * 물리적인 연결 상태에 집중하는 단어

    * 네트워크 망에 몇 개의 장치가 붙어 있는가?"를 따질 때 주로 사용

* **Host**

    * 네트워크를 통해 "무엇인가 (데이터, 서비스)를 주고받는 주체"에 집중하는 단어

    * 운영체제가 돌아가고 응용 프로그램이 실행되는 장치를 의미

* $\therefore Host \subset Node$

## 2. LAN vs WAN

* **LAN:** 관리자가 직접 설정을 바꾸고 통제할 수 있는 내부망

* **WAN:** 관리자의 통제권 밖인 통신사 (ISP)가 제공하는 외부망

* **현대적 관점:** 물리적 거리가 아니라 관리 권한 (제어 가능 여부)에 따라 구분

## 3. Units

### 3.1 Not Speed, it's Bandwidth

* **Network (Bandwidth)**

    * bit 단위 사용 (`bps`)
    
    * 속도가 아니라 초당 전송량

    * `Mbps`, `Gbps`

* **Storage (Capacity)**

    * Byte 단위 사용 (`B`)
    
    * 데이터의 실제 크기

    * `GB`, `MB`

### 3.2 Throughput

* 대역폭 내에서 실제로 전송에 성공한 진짜 데이터의 양

## 4. Protocols

* **Protocols:** 상호 간의 약속된 규칙, 규약, 규범

* **Communication Protocols:** 디지털 장치들이 데이터를 주고받기 위해 사용하는 공통된 통신 언어

* **핵심:** 기기나 제조사가 달라도 같은 프로토콜을 사용하면 통신 가능

## 5. OSI Model

* **Header:** 캡슐화 시 데이터 앞에 붙는 제어 정보

* **Trailer:** 캡슐화 시데이터 뒤에 붙는 추가 정보

    * 주로 2계층 (Data Link Layer)에서 추가

* **PDU:** 각 계층의 프로토콜이 데이터에 자신의 헤더를 붙여 만든 독립적인 통신 단위

* **Encapsulation:** 상위 → 하위 레이어로 내려가며 헤더를 입히는 과정

    * **Data**

    * **L4 (Transport): Segment**
    
        * $\therefore \text{Segment} = \text{L4 Header} + \text{Data}$
    
    * **L3 (Network): Packet**
    
        * $\therefore \text{Packet} = \text{L3 Header} + \text{Segment (Data)}$
    
    * **L2 (Data Link): Frame**
    
        * $\therefore \text{Frame} = \text{L2 Header} + \text{Packet (Data)} + \text{Trailer}$

    * **Bitstream**

* **Decapsulation:** 하위 → 상위 레이어로 올라가며 헤더를 제거하는 과정.

    * **Bitstream**

    * **L2 (Data Link): Frame → Packet**
    
        * $\therefore \text{Packet (Data)} = \text{Frame} - (\text{L2 Header} + \text{Trailer})$
        
    * **L3 (Network): Packet → Segment**
    
        * $\therefore \text{Segment (Data)} = \text{Packet} - \text{L3 Header}$
        
    * **L4 (Transport): Segment → Data**
    
        * $\therefore \text{Data} = \text{Segment} - \text{L4 Header}$

    * **Data**
